# Plan 01-02: Build Data Foundation

## Goal
Clean data pipeline: OHLCV + funding rates for top-10 liquid pairs, Parquet cache, liquidity filter, stationarity enforcement. Single source of truth for all downstream phases.

## Tasks

1. **Create config module** — `crypto_ml_edge/config.py`: top-10 pairs by liquidity, timeframes (1h, 4h), Binance fee model, data paths.

2. **Create data fetcher** — `crypto_ml_edge/data_fetcher.py`: Reuse Binance REST pattern from `ml_crypto_predictor/enhanced_models/data_fetcher.py`. Add funding rate fetching. Parquet cache with configurable TTL.

3. **Create data quality module** — `crypto_ml_edge/data_quality.py`: Validate no gaps, no NaN OHLCV, timestamps monotonic. Assert function that fails loudly.

4. **Create stationarity module** — `crypto_ml_edge/stationarity.py`: Fractional differentiation (d=0.4) from feature_engine_v2.py. Percentage returns as fallback. No raw prices pass through.

5. **Create liquidity filter** — In config or data_fetcher: exclude pairs where average daily volume < threshold.

6. **Unit tests** — `crypto_ml_edge/tests/test_data.py`: Verify no lookahead, stationarity, cache works.

## Key Decisions
- Direct Binance REST (no CCXT) — existing code proves this works fine
- Reuse `data_fetcher.py` pagination logic (batch_fetch_klines)
- Top-10 pairs determined dynamically by 30-day average volume
