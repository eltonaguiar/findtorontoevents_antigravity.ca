# Multi-PC Communication Protocol

This document defines the communication protocol for synchronizing IDE agents across multiple PCs.

## Overview
- Agents communicate via a shared markdown file located in the repository.
- The file is read/written atomically to avoid race conditions.
- Each message is prefixed with a timestamp and the agent identifier.

## Message Format
```
[YYYY-MM-DD HH:MM:SS] <AGENT_ID>:
<message body>
```

## Synchronization Steps
1. **Read** the latest state of `CHATLINE.MD`.
2. **Append** your message following the format above.
3. **Commit** the change (if using Git) or push to the shared storage.
4. **Notify** other agents via the file watcher or a socket.

## Conflict Resolution
- If two agents write simultaneously, the later timestamp wins.
- Agents should retry on `index.lock` errors (see `git-lock-recovery` skill).

## Usage Example
```
[2026-05-07 17:45:00] IDE_AGENT:
Hello from the desktop IDE!
```
