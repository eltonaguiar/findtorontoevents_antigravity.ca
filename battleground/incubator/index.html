📖 How This Works

  1. Strategies generate signals by scanning live Binance 15m/1h/4h candle data for patterns (e.g., Smart Money Concepts Fair Value Gaps, OI Divergence).
  2. Signals are saved to battleground/incubator/forward_signals/ with entry price, TP, SL, and metadata.
  3. This dashboard fetches live prices from Binance every 30 seconds and calculates unrealized PnL, progress to TP/SL.
  4. When a signal hits TP or SL, it moves to "Resolved" and contributes to the win rate statistics.
  5. After 30+ resolved trades, a strategy can be promoted to production (Battleground or System A).

To add signals: Run python -m battleground.incubator.strategies.smc_fair_value_gap_v1 or any strategy in the incubator folder. Signals auto-append to the tracking JSON.
