# ServiceNow & Salesforce Job Discovery Plan

## Objective
Develop a systematic methodology to discover high-quality ServiceNow and Salesforce developer jobs in Toronto, GTA, and Canada remote locations.

## Methodology Overview
The discovery process will use a multi-layered approach combining:
- Direct company career page scanning
- Job aggregator scraping
- Certification-based filtering
- Location-targeted searching
- Real-time job feed monitoring

## Phase 1: Data Sources Identification
### ServiceNow Sources
- ServiceNow official careers page
- Major consulting firms (BDO, Huron, ComTec, Platform 6)
- Government contractors (MANTECH, ActioNet, NTT DATA)
- Job aggregators: Remotery, FlexJobs, Dice, Indeed, LinkedIn

### Salesforce Sources
- Salesforce official careers
- Consulting firms (Kicksaw, Decisive Point, Marsh McLennan)
- Government contractors (Cherokee Federal)
- Job aggregators: BuiltIn, NeuraFlash, Indeed, LinkedIn, FlexJobs

## Phase 2: Search Patterns
### ServiceNow Keywords
- "ServiceNow Developer", "ServiceNow Architect", "ServiceNow Consultant"
- Certifications: "CSA", "CAD", "CIS-CSM", "CMA", "CTA"
- Technologies: "ITSM", "CSM", "GRC", "HRSD", "IRM"

### Salesforce Keywords
- "Salesforce Developer", "Salesforce Administrator", "Salesforce Architect"
- Certifications: "Admin", "PD I", "PD II", "Advanced Admin"
- Technologies: "Apex", "LWC", "SOQL", "Visualforce", "Agentforce"

## Phase 3: Location Filters
- Toronto, Ontario
- Remote Canada
- Remote USA/Canada (hybrid)
- GTA cities: Mississauga, Brampton, Vaughan, Markham, Richmond Hill

## Phase 4: Quality Criteria
- Must require relevant certifications
- Must specify Toronto/Remote Canada location
- Must be active (posted within last 7 days)
- Must have clear role description and requirements
- Must have direct application link

## Phase 5: Validation Process
- Verify job is still active
- Check certification requirements match
- Validate location requirements
- Confirm application process works
- Extract key details for BESTIEJOB integration

## Timeline
- Initial scan: 2 hours
- Daily refresh: 30 minutes
- Weekly deep dive: 2 hours

## Tools Required
- SubQ API for document comparison and decision making
- Web scraping tools
- Local database for job storage
- Notification system for new postings
