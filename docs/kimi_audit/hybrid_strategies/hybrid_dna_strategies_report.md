## ⚠️ RISK WARNINGS

### Hybrid-Specific Risks
1. **Over-Optimization:** Combining strategies increases curve-fitting risk
2. **Complexity:** More rules = more things that can break
3. **Signal Overlap:** May reduce trade frequency significantly
4. **Execution:** Requires precise timing and advanced platforms

### Mitigation Strategies
- Test each component separately before combining
- Use out-of-sample validation religiously
- Start with 0.5% risk (lower than single strategies)
- Monitor for correlation breakdown between components
