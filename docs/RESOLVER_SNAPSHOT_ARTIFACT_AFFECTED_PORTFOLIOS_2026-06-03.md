# Snapshot-Resolver Artifact — Affected Portfolios Register (2026-06-03)

Companion to `reports/ai_tournament_winrate_audit_2026-06-03.md`.
Scope: every portfolio / paper-trading tracker in the repo was reviewed to decide
whether its reported win-rate / profit-factor is inflated by **the snapshot-resolver
artifact** — resolving trade outcomes from a single daily spot price (no intrabar
high/low OHLC path), checking TP before SL, and booking P&L at the barrier price.

A portfolio is **AFFECTED** if either is true:
1. It consumes AI-tournament picks (`tournament_picks` / `ai_tournament_*`), or
2. Its own outcome resolution uses the single-snapshot / no-intrabar / barrier-price
   mechanism (the same WR-inflating pattern, independently reimplemented).

Note added per-module: each affected producer's module docstring carries a one-line
`SNAPSHOT-RESOLVER ARTIFACT (2026-06-03)` pointer to this file. The JSON data outputs
are regenerated by cron, so the durable note lives in the producer source, not the data.

## The correct (intrabar) resolvers — for reference

- `alpha_engine/outcome_resolver.py` `_scan_ohlc_for_touch` (:559-598) — **gold standard**:
  intrabar OHLC, SL checked first (conservative), gap-through aware. Drives the main
  `/audit` `JSON_PICK_SOURCES` ledgers — those are NOT corrupted.
- `alpha_engine/swing_resolver.py` (:165-181) — gap-through aware.
- `audit_trail/universal_pick_resolver.py` `_check_tp_sl_intrabar` (:529) and
  `tools/swarm/outcome_resolver_swarm.py` (:138) — intrabar high/low, but check TP before
  SL within a bar (residual optimistic bias; the swarm one only fetches daily bars).

## Remediation (tracked in the audit report)

The fix is repo-wide: replace single-snapshot resolution with intrabar OHLC path replay
(resolve to the **adverse** barrier when a bar spans both TP and SL), reusing
`outcome_resolver._scan_ohlc_for_touch`. This is the "intrabar resolver is THE upstream
T2 blocker" item already in repo memory. Until then, the WR/PF on every AFFECTED portfolio
above is overstated and must not be used to size up or promote a strategy.
