# Agent bus handoff — KOL execution slice (cursor-kol-bus)

**Agent:** `cursor-kol-bus` (Cursor)  
**Rationale:** Social `predictions` rows and `kol_consensus` were mixing **DB/registry asset class** with symbol-only heuristics, and **news headline consensus** was scored like **multi-category KOL** agreement. Goal: correct routing for multi-asset exports and **down-weight news-derived** consensus in elite scoring without unbanning the `predictions` system in `cross_aggregation` (still **BANNED** there by design).

---

## Files changed (what / why)

### 1. `alpha_engine/isolated_signal_integrator.py`

| Item | Detail |
|------|--------|
| **Added** | `_map_db_asset_class_field(raw)` — maps DB strings `crypto`, `equity`, `etf`, `forex`, `futures`, `commodity` → integrator enums `CRYPTO`, `STOCKS`, `FOREX`, `FUTURES`, `COMMODITY`. |
| **Changed** | Quality gates: read `raw_pick["asset_class"]`; for `source_name == "predictions"` **prefer** mapped DB class over `_identify_asset_class(symbol)`; if symbol class is `UNKNOWN`, use DB hint when present. |
| **Why** | Scrapers can set `asset_class` in SQLite; exports to `active_predictions.json` were losing that signal when the integrator overwrote category from symbol pattern only. |

### 2. `predictions/kol/kol_consensus_bridge.py`

| Item | Detail |
|------|--------|
| **Added** | `news_inferred` detection: `sig["_news_consensus"]`, or `consensus_signal_source == "news_inferred"`, or `categories == ["news_inferred"]`. |
| **Added** | Pick field `consensus_signal_source`: `"news_inferred"` \| `"kol_weighted"`. |
| **Changed** | `reason`: news uses “News headline consensus… not verified individual KOL calls”; KOL path keeps “KOL consensus: N KOLs from M categories…”. |
| **Why** | Downstream (`elite_scorer`, humans) can distinguish **headline clustering** from **registered KOL** clusters; avoids overstating “KOL” when sources are gnews/mediastack-style feeds. |

### 3. `alpha_engine/elite_scorer.py`

| Item | Detail |
|------|--------|
| **Changed** | `_check_kol_alignment` cache build: if `consensus_signal_source == "news_inferred"`, shrink alignment bonus (×0.25, cap 1). |
| **Changed** | Mode A KOL block (pick already has consensus metadata): after WR bonus, if `news_inferred`, `kol_pts = min(kol_pts * 0.25, 2.0)`. |
| **Why** | Prevents news-only consensus JSON from inflating elite scores the same as category-diverse KOL agreement. |
