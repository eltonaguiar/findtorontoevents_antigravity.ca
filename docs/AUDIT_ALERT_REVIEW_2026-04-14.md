## Performance Alerts System Design

Alerts are generated by `cross_aggregation/performance_alerts.py`:
- **Strategy degradation**: Rolling 7d WR vs baseline (prior closed or system_stats). Requires `_MIN_RECENT_TRADES=10`, `_MIN_PRIOR_TRADES=18`, `_RELATIVE_DROP=0.20`, `_MIN_ABSOLUTE_DROP_PP=10`.
- **Correlation spike**: Single source >60% of active picks → HIGH, >40% → MEDIUM.
- **Data staleness**: Source with no pick in 56h → MEDIUM. No picks at all → CRITICAL.
- **Daily loss**: Portfolio unrealized PnL < -5% → CRITICAL, < -3% → HIGH.

Penalties from alerts feed into `ROLLING_7D_DEGRADATION_STRATEGY_PENALTIES` in `quality_gates.py`, which applies score penalties during `_apply_score_penalties()`.
