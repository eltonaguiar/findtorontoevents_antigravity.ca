## Generator script issues

`scripts/generate_strategy_audit_rounds.py` (96 LoC):

1. **Hardcoded WSL path** `/mnt/e/findtorontoevents_antigravity.ca/...` — fails on Windows; only runs from WSL.
2. **Asset class detection naive** — string-matches strategy name (`"pairs" in name` → CRYPTO), wrong for most.
3. **Performance numbers identical** every round (lines 78-89 of generator have a static dict).
4. **No real strategy registry pull.** Generator does NOT read `audit_dashboard/data/dashboard_data.json::leaderboard` or `STRATEGY_WEIGHT_OVERRIDES`. Could cycle through 100+ real strategies with real metrics, doesn't.
5. **Cycle modulo means at 5000 rounds** = 500 copies of each of 10 names. Disk cost ~5000 × 3 files × ~500 bytes = ~7.5 MB of duplicate stubs. Git history bloat.

## Hermes 5000-round plan — recommendation

**Don't.** Generating 4,800 more identical stubs adds zero signal. Convert the effort to:

### Option A — kill rounds dir + replace with one real doc

Delete `docs/strategy-audit-rounds/` entirely. Write one canonical `docs/STRATEGY_REGISTRY.md` that auto-renders from `dashboard_data.json::leaderboard` and `STRATEGY_WEIGHT_OVERRIDES` — actual live strategies with actual fwd_wr/fwd_pf/n + author + status. ~1 page, always fresh. Generator is `tools/build_strategy_registry.py` (~50 LoC).

### Option B — rewrite generator to do per-strategy real audit

Instead of 200 fake rounds, generate 1 doc per real strategy (target ~120 strategies = ~120 dirs). Each round pulls:

- `strategy.md` ← actual function source from `alpha_engine/*.py` (use `inspect.getsource`)
- `performance-report.json` ← actual rows from `dashboard_data.json::leaderboard` + `closed_picks` aggregates
- `research-optimizations.md` ← left empty for human/swarm to fill (with template hint)

Then 1 cron run = freshly regenerated rounds with real metrics; rotation through strategies happens by reading the registry, not by modulo cycle.

### Option C — if hermes insists on numerical "rounds"

Make each round a real audit cycle (e.g., weekly): round 381 = 2026-05-09 audit of top-10 leaderboard by (fwd_pf desc), round 382 = next week, etc. One round per week = 5000 rounds = 96 years. Or one per day = 13 years. Neither makes sense; "rounds" is the wrong unit. Use dates instead.

## Recommended action

1. **Pause hermes 5000-round generation now.** Each batch is wasted commits.
2. **Decide A/B/C above** before any more rounds get generated.
3. **If A:** ship `tools/build_strategy_registry.py` + `docs/STRATEGY_REGISTRY.md`, then `git rm -r docs/strategy-audit-rounds/`.
4. **If B:** rewrite `scripts/generate_strategy_audit_rounds.py` to pull from real sources; regenerate 001-200 with real content.
5. Coordinate via cross-pc protocol (hermes is on other PC) before next batch.
