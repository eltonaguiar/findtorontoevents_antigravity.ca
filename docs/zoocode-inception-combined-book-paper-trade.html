Combined-Book Paper-Trade
plan / achievements / future research

Standalone backtest harness + paper simulator for a three-sleeve (trend / quality-value / put-write) book, built to reproduce a documented Grok-benchmarked edge proof. Date: 2026-10-19. Branch: feat/combined-book-paper-trade.

1 · Plan (what this work set out to do)

Build a standalone combined-book paper-trade module, before trading, and only after reproducing the reference backtest numbers. Core steps:

  1. Freeze the rules (RULES.md + SHA-256) and the instrument universe.
  2. Build the data layer: raw-ETF history for the live pilot, plus a separate research dataset that extends history back to ~1988 using spliced mutual-fund proxies, Ken French high-OP/BE-ME portfolios, and the CBOE PUT index.
  3. Build the three sleeves, the inverse-vol combiner, the backtest harness, and the statistical go-live / kill gates.
  4. Reproduce the reference targets — 5% overlay: CAGR 6.5% ±1.5pp, Sharpe 1.20 ±0.25, MDD −14.4% ±3pp; coin-flip control rejected.
  5. Cross-check both datasets on 2013+ (they should agree).
Honesty rule: reproduce the exact reference numbers first; if a target misses, report the per-sleeve numbers side-by-side with results.csv rather than loosening tolerances.

What was built

  • combined_book/fetch.py — raw + research fetch/builders: splice map (SPY←VFINX, TLT←VUSTX …), Ken French parser, CBOE PUT index.
  • combined_book/research.py — research sleeve builder, reference rolling inverse-vol weights, 5% target-vol overlay, reference backtest mirror.
  • combined_book/simulator.py — sleeve combination (exclude missing + renormalize), book return series, stats.
  • combined_book/cli.py — research-backtest subcommand.
  • Tests (tests/test_combined_book_reproduction.py) incl. a research-dataset reproduction test for the reproducible subset.

Bugs found & fixed

  • Sleeve no-data bug: a sleeve with no data that month used to sit at 0% (cash). Now excluded and the remaining weights renormalized per row.
  • Ken French fixed-width parser bug: header-derived character ranges didn't match the data rows (header uses multi-space column gaps; data rows use single spaces). OP Hi 30 for 2008-10 read +18.3% instead of the true −15.32%. Rewrote the parser to whitespace-split both header labels and data rows.

4 · Areas for future research

  • Refresh Ken French data. The staged files are the Aug-2022 snapshot (monthly ends 2022-08); the reference ran to Oct-2026. A refreshed download would lengthen the quality sleeve's recent tail.
  • Match the trend-sleeve price feed. Re-run TSMOM against the reference prices.pkl snapshot (or an identical vendor feed) to tighten CAGR/Sharpe reproduction.
  • Overlay target selection. Extend the pre-2015 fit / walk-forward vol-target selection to a full out-of-sample regime test.
  • Transaction-cost & borrow modelling. Add per-sleeve cost, margin, and leverage constraints to the paper ledger.
  • Go-live gate validation. Feed the reproduced series through the Wilson/binomial and deflated-Sharpe gates with a full Monte Carlo bootstrap.
