# 7-Day Pilot Measurement Plan for BestieJob Job-Hunt Swarm

## Day 0: Preparation

1. Define equal request/time budgets for each of the 4 angles (C GTA cities, A company portals, D partners, B CA govt).
2. Establish go/no-go criteria based on day-0 checkpoints.
3. Prepare day-0 checkpoints for each angle.

## Day 1: Start of Pilot

1. Begin sending requests to each angle according to their respective request/time budgets.
2. Record incremental unique yield for each angle.
3. Verify job leads using canonical verifier.
4. Measure verification quality and issuer→discovery freshness lag (+48h day 7) for each verified job.
5. Track cost per verified job and compare exclusive vs shared finds.
6. Establish day-1 checkpoints for each angle based on go/no-go criteria.

## Days 2-6: Ongoing Measurement

1. Continue sending requests to each angle according to their respective request/time budgets.
2. Update incremental unique yield for each angle daily.
3. Verify job leads using canonical verifier.
4. Measure verification quality and issuer→discovery freshness lag (+48h day 7) for each verified job.
5. Track cost per verified job and compare exclusive vs shared finds.
6. Establish daily checkpoints for each angle based on go/no-go criteria.

## Day 7: End of Pilot

1. Complete sending requests to each angle according to their respective request/time budgets.
2. Record final incremental unique yield for each angle.
3. Verify remaining job leads using canonical verifier.
4. Measure final verification quality and issuer→discovery freshness lag (+48h day 7) for each verified job.
5. Track final cost per verified job and compare exclusive vs shared finds.
6. Establish day-7 checkpoints for each angle based on go/no-go criteria.
7. Rank angles on evidence of incremental unique yield, verification quality, issuer→discovery freshness lag, cost per verified job, and exclusive vs shared finds.
