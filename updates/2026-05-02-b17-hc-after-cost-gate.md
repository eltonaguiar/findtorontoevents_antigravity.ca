## What shipped

### 1. After-cost field stamping (`audit_trail/dashboard_generator.py`)

New module-level functions `_load_ac_strategy_index()` and `stamp_after_cost_fields()` added between the concept-registry block and `_normalize_pick()`. Called from inside `_normalize_pick()` immediately after `assign_concept_fields()`.

Every pick that flows through the dashboard normalization path now receives:

| Field | Source | Meaning |
|-------|--------|---------|
| `after_cost_net_per_trade` | B16 artifact `after_cost_mean_pnl_pct` | Mean after-cost PnL % per trade for this strategy |
| `wilson_lb_wr` | B16 artifact `wilson_lb_wr_pct` | Wilson 95% lower bound on strategy WR |
| `is_ac_survivor` | B16 artifact `both_survive` | True if after-cost AND wilson_lb both pass |

**Null semantics:** `None` means "strategy not in B16 index" (unknown), not "non-survivor." The gate treats `None` fields as passthrough — only blocks when both fields are populated AND both criteria fail.

**Staleness guard:** artifact older than 25h → all three fields are `None` (no stale data stamped).

**Index structure:** `(strategy_lower, asset_class_upper)` compound key with `strategy_lower` fallback for picks without an asset class.

### 2. Shadow HC gate (`tools/hc_gates_python.py` + `tools/dashboard_hc_rules.py`)

New function `passes_hc_after_cost(pick)` appended to both files. Default-OFF behind `HC_AFTER_COST_GATE_ENABLED=1` env flag.

**Gate criteria (when ON):**
- `after_cost_net_per_trade > 0` (strategy must have positive expected value after costs)
- `wilson_lb_wr >= 50.0%` (lower-bound WR at 95% confidence must beat break-even)

**Passthrough cases (always returns True):**
- Flag OFF (default production state)
- `after_cost_net_per_trade is None` or `wilson_lb_wr is None` (unknown strategy)
- Malformed non-numeric fields

### 3. Tests (`tests/test_hc_after_cost_gate.py`)

19 tests, all passing:
- `stamp_after_cost_fields`: null strategy, compound key, fallback key, unknown strategy, non-survivor, case-insensitivity
- `passes_hc_after_cost`: flag off, flag 0, survivor passes, negative net fails, low lb fails, exact boundary (50.0), None fields, malformed
- `_load_ac_strategy_index`: empty glob, stale artifact, fresh artifact, cache hit
- Integration: `_normalize_pick()` stamps fields from live index
