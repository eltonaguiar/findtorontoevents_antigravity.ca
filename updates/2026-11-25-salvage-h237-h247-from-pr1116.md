## Why

PR #1116 cannot be merged whole. An in-memory 3-way merge (`git merge-tree --write-tree origin/main refs/prrev/1116`) reports **38 conflicted files** — 14 code/CI, 7 JSON state, 15 markdown, 2 other. Resolving 14 semantic code conflicts by hand is exactly where a merge silently drops someone else's invariant.

But the branch does contain content main lacks. Two hazards make the whole-merge unsafe:

1. `alpha_engine/money_ready_verdict.py` conflicts with main's `_population_invariant()` (added line 1642, called 1947). A *separate* PR (#1046) rewrites `NB_TRIALS_BY_CLASS` CRYPTO 14 → 629 in the same file. Landing both through hand-resolved conflicts entangles the DSR trial count with the population invariant, so which number produced which verdict stops being traceable.
2. `alpha_engine/cost_gate.py` is `add/add` — both branches independently created that path.

So the safe subset is extracted here, and the code lands separately.
