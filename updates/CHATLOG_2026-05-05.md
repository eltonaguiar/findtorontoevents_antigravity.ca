## Task 1: Apply 4 Critical Swarm Fixes

### Root Cause
A `RUFLO_TOOLS_SWARM_COMPREHENSIVE_REVIEW.md` audit identified 4 critical issues in the swarm tooling:

1. **CRITICAL — Cost overrun**: `estimate_cost_usd()` used a flat `gpt-4o-mini` rate for openrouter regardless of `OPENROUTER_MODEL` env var, causing 100x overruns (e.g. $0.01 est → $150 actual for claude-opus-4)
2. **HIGH — Thread safety**: `run_swarm_audit()` used bare `results = {}` shared across threads without any synchronization
3. **HIGH — HTTP deadline enforcement**: `_post()` had per-request timeout but no overall call-budget enforcement across retries
4. **MEDIUM — Key sanitization gaps**: 10 regex patterns missing modern formats (JWT, MongoDB, PEM, Azure, AI API keys, etc.)

### Files Modified

#### `tools/swarm/swarm_run.py` — Cost Overrun Fix (CRITICAL)

- Added `OPENROUTER_MODEL_RATES` dict with 22 model-specific rates from openrouter.ai pricing (OpenAI, Anthropic, Google, DeepSeek, xAI, Meta, Mistral, free-tier models)
- Added `OPENROUTER_UNKNOWN_MULTIPLIER = 10.0` (safe overestimate for unknown models)
- Added `_get_openrouter_model()` helper (reads `OPENROUTER_MODEL` env var)
- Added `_lookup_openrouter_cost(model_tag)` with resolution order: exact match → provider-prefix fallback → 10x unknown-safety multiplier → gpt-4o-mini fallback
- Modified `estimate_cost_usd()` to route openrouter through `_lookup_openrouter_cost()`
- Removed duplicate `openrouter` key in `COST_PER_1K_TOKENS` dict (cleanup from multi-pass edits)
- Fixed unreachable docstring step 4 in `_lookup_openrouter_cost()` (reviewer catch)

**Functional verification:**
```
default openrouter (gpt-4o-mini):    $0.0028
claude-opus-4 override:              $0.3375  ← 120x correction ✓
deepseek + openrouter + xai mix:     $0.0701
unknown model (10x safety margin):   $0.0259
```

#### `.ruflo/orchestrator.py` — Thread Safety + Tier Fixes (HIGH)

- Added `results_lock = threading.Lock()` protecting all reads/writes to the shared `results` dict in parallel audit path
- Expanded `sanitize_keys` regex patterns from 10 to 22 (covers JWT, MongoDB, PEM, Azure, modern GitHub, AI API keys)
- Changed default tier from `free` to `hybrid` (paid then free fallback)
- Added `--tier` and `--check-keys` CLI options
- Fixed REPO_ROOT path to use `Path(__file__).resolve().parent.parent` for cross-platform compatibility

#### `tools/swarm/api_consult.py` — HTTP Deadline Enforcement (HIGH)

- Added `_deadline` parameter to `_post()` with `DEFAULT_HTTP_TIMEOUT=60` (per-attempt cap) and `DEFAULT_MAX_TOTAL_DURATION=180` (overall budget)
- Deadline check raised before each retry attempt — raises `TimeoutError` if exceeded
- Per-request timeout clamped to `min(timeout, max(5, int(remaining * 0.8)))` to stay within budget
- Expanded `_sanitize_for_log()` regex patterns from 10 to 22 (matching orchestrator.py)

#### `tools/swarm/worker_runner.py` — Empty Envelope Retry Fix

- Added retry-once logic for `call_gemini()`, `call_opencode_or_kilo()`, `call_copilot()` when rc=0 but output is empty (empty-envelope bug)
- Evidence: swarm_runs/_calls.jsonl showed kilo/opencode returning rc=0 with 0 bytes on 2026-05-04, wasting 2-10s per retry attempt
