## 2. Query Executed

```sql
SELECT source_db, source_table, COUNT(*) as n
FROM bt_backtest_trades
GROUP BY source_db, source_table
ORDER BY n DESC
LIMIT 20;
```

**Rationale:** Identify the top 20 source combinations by volume. Any source containing `live`, `production`, `real`, or `filled` is a candidate for the "production" subset. Everything else is presumed backtest/synthetic.
