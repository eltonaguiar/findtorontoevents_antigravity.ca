📊 Why are all forward metrics zero?
1
Model trains on history — The ML ensemble (RF + Gradient Boost) is trained on 1700+ candles of historical data per pair, using walk-forward validation so it never sees future data.
2
Picks are generated on LIVE data — Every pick you see below was predicted using only data available at that moment. No look-ahead, no peeking, no hindsight. Each pick gets a timestamp (EST) of when it was made.
3
Picks must HIT TP or SL to count — A forward pick is "resolved" only when the live market price reaches either the Take Profit or Stop Loss level. Until then, the pick is active (being tracked). This typically takes 12-72 hours.
4
