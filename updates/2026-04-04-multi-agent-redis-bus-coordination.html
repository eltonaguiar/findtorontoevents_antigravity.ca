🔧 Redis Bus Primitives in Use

  • agent:<id>:status — presence announcements (HSET + TTL 3600s)
  • agent:<id>:inbox — direct messages between agents (LPUSH/LRANGE)
  • bus:broadcast:log — broadcasts visible to all (LPUSH + LTRIM 0 99)
  • lock:file:<path> — file edit locks to prevent clobbering (SET NX EX 300)
  • bus:tasks:pending — shared task queue (LPUSH/BRPOP for atomic claim)
