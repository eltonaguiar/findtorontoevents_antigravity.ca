2. Quick-Start Guide

  1. Open TradingView - Navigate to tradingview.com/chart
  2. Pine Editor - Click the Pine Editor tab at the bottom
  3. Copy the Code - Open Simpletonv001_ANTIGRAVITY.pine and copy
  4. Paste and Save - Paste into Pine Editor, click Save then Add to Chart
  5. Select Strategy - Open Settings, pick from 8 strategies
  6. Backtest - Click Strategy Tester tab for performance metrics
  7. Signal Engine - Repeat with SignalEngine_ANTIGRAVITY.pine for live signals
