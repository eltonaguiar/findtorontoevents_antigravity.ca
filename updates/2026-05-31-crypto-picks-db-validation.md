## Queries Executed

### 1. `at_raw_picks` — All CRYPTO 90d Decisive Picks
```sql
SELECT COUNT(*) as n,
       SUM(CASE WHEN status = "WON" THEN 1 ELSE 0 END) as wins,
       SUM(CASE WHEN status = "LOST" THEN 1 ELSE 0 END) as losses,
       SUM(CASE WHEN pnl_pct > 0 THEN pnl_pct ELSE 0 END) as sum_pos,
       SUM(CASE WHEN pnl_pct < 0 THEN pnl_pct ELSE 0 END) as sum_neg
FROM at_raw_picks
WHERE asset_class = "CRYPTO"
  AND closed_at >= DATE_SUB(NOW(), INTERVAL 90 DAY)
  AND status IN ("WON", "LOST")
```
**Result:** n=11,600, WR=39.95%, PF=3.1785

### 2. `picks` — All CRYPTO 90d Decisive Picks
