How Cross-System Consensus Works (Plain English)

What is consensus? — Instead of trusting one system, the Cross-System Monitor checks if multiple independent systems agree. If Mercury 2, KIMI, and Alpha Engine all say "BUY BTCUSDT", that signal is stronger than any single system alone. Like asking 3 doctors instead of 1.

Which systems feed in? — 12 systems: Mercury 2 (XGBoost), KIMI (81 algorithms + RF ranker), Alpha Engine (100 strategies + LightGBM), Crypto ML Edge (per-coin LightGBM), Claude Gainer (RF + XGBoost), ML Battleground (3 systems), Signal Engine, Breakout detectors, and more.

A "consensus pick" means ≥2 independent systems agree on the same symbol and direction. More systems agreeing = higher confidence. The monitor also detects conflicts (one system says BUY while another says SELL).
