Table 2 — Live playbook signals (1h)

What is this? A real-time strategy scanner. Every time you load this page (or click "Refresh"), it pulls the latest closed 1-hour candle from Binance and checks each strategy's entry rules against that bar. If a row shows Valid SHORT or Valid LONG, that strategy's conditions were met on the most recent completed candle.

How it differs from Table 1: Table 1 (QuanEngine) is a daily consensus vote — "do the strategies agree?" This table is a live per-strategy breakdown — "which individual strategy is firing right now?" The QuanEngine column here links the two: it shows whether the QuanEngine also agrees with that strategy's direction.

This is not a trade signal — confirm on chart and in your Hyro terminal before entering. Config: audit_dashboard/data/hyro_live_strategies.json.

Table 4 — Signal Strength & Pick Performance

What is this? Validates whether past signals actually hit their TP or SL by checking real Binance price action from signal time forward. Each strategy gets a Strength Score (0–100) based on win rate, sample size, edge quality (MFE/MAE), and signal decisiveness.

How to read it: A/A+ = strong track record, trade with confidence. B/C = moderate — use with extra confirmation. D/F = weak or insufficient data — avoid or resize down. Run python tools/hyro_pick_performance_validator.py --save to refresh.
