Thresholds — the audit pipeline runs on an hourly cron, so: ● fresh = updated within 2h · ● stale = 2–6h old (amber warning) · ● DEAD = older than 6h or missing (red) · ● unknown = server did not report a timestamp.
Age is measured from the file's HTTP Last-Modified on the live site — i.e. when the pipeline actually finished writing it, not when the code changed.
