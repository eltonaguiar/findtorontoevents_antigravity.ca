Institutional Readiness Plan — 90-Day Refresh

2026-05-24 · Living document

Two-stage plan to lift /audit from the current PF 1.3–1.55 baseline into a paper-trustworthy state in 90 days and an institutional-pilot state after a further 6-month clean window. Synthesized from a 4-AI external consult (Mercury 2 + Grok + ChatGPT + Gemini) and reviewed by a 5-engine swarm (deepseek + groq + inception + pollinations + ofox).

The strategic re-frame

Old optimization target: "Find explosive winners" — high score + high upside, freshness-weighted.
New optimization target: "Preserve capital while compounding asymmetrically."

All four external reviewers converged on this. It cascades into ranking, filters, exits, portfolio construction, swarm design, and confidence systems simultaneously. Every workstream below is anchored to it.

Two-stage gate

Per the swarm critique (5/5 engines flagged the original "Sharpe > 1.5 in 6 months" as too tight for a system at PF 1.3–1.55), the gate is now two stages so we can show progress without lying about institutional-readiness.

Seven workstreams

A · Honesty layer

P0Freshness SLA per class, cross-provider price reconciliation, Platt/isotonic score calibration, lookahead-CI guard, honest stat surface. A1 + A3 block downstream; A2/A4/A5/A6 run parallel.

B · Edge quality

P1Transaction-cost layer, regime classifier + macro-calendar blackout, vol-adjusted sizing, exit-logic upgrade. Starts Week 2 once A1+A3 land.

C · Portfolio construction

P1Correlation cap (pairwise ≤ 0.6), sector cap ≤ 30%, factor budget, vol-targeting, pairs/co-integration sidecar, 5% per-pick VaR cap.

D · Speculative split

P1Step 1: speculative_flag boolean + visual tabs. Step 2 (conditional): full engine split — only if Step 1 surfaces gate contamination.

E · Swarm redesign

P2Replace stylistic personas with factor-orthogonal specialists + Gatekeeper veto agent. Nightly PCA diversity guardrail. Wilson-CI-weighted aggregator.

F · Coverage + new products

P2Wire missing ETF/Bond/Commodity emitters; per-class metric expansion; low/no-fee no-min mutual-fund ranker on /audit/mutual-funds.html.

G · Governance / monitoring / rollback

P0 (added per swarm)Real-time alerts, circuit-breaker on Stage-1 floor violation, data lineage, golden-set regression in CI, explainability surface, quarterly stress replays.
