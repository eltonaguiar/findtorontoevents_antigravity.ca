Bybit Copy Trading Leaderboard\n- **URL**: [`https://www.bybit.com/en/copyTrade/trader/leaderboard`](https://www.bybit.com/en/copyTrade/trader/leaderboard/)\n- **Metrics**: Rank, Followers, Total PnL, ROI (cumulative), Max Drawdown, Win Rate, AUM.\n- **Top Performers Example** (from recent screenshot analysis):\n  - #1 Masters often show 400-1200% ROI, DD <15%, 100k+ followers.\n  - Verifiable: Exchange-computed curves, historical.\n- **Scrapability**: High.\n  - Leaderboard: Div/table with CSS `.leaderboard-row`, `.roi-value`.\n  - Profiles: Click trader name → \"Trade Record\" tab → Table of trades: Open Time, Symbol, Side, Entry Price, Size, Close Time, PnL.\n  - Hold time: Close - Open.\n  - Entry criteria: Infer from price action, funding rates (public API).\n  - Example Puppeteer scrape:\n    ```javascript\n    await page.goto('https://www.bybit.com/en/copyTrade/trader/[ID]/');\n    await page.waitForSelector('.trade-history-table');\n    const trades = await page.evaluate(() => Array.from(document.querySelectorAll('.trade-row'), row => ({\n      openTime: row.querySelector('.open-time').textContent,\n      entry: parseFloat(row.querySelector('.entry-price').textContent),\n      closeTime: row.querySelector('.close-time').textContent,\n      pnl: parseFloat(row.querySelector('.pnl').textContent),\n      holdHours: (new Date(row.querySelector('.close-time').textContent) - new Date(row.querySelector('.open-time').textContent)) / 3600000\n    })));\n    ```\n- **Reverse Eng Examples**: Short holds (4-12h), long on funding positive, scalps on BTC/ETH.\n\n### 2.
