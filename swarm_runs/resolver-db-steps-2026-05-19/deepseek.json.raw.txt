## Concrete Implementation Plan

### 1. Backup Strategy (pre-step)
- **Snapshot table:** `at_raw_picks` → `at_raw_picks_bkp_YYYYMMDD_HHMM`
- **Also snapshot:** `alpha_engine_picks` (if re-resolve writes to it) → same naming convention
- **Command:** `CREATE TABLE at_raw_picks_bkp_20250320_1430 AS SELECT * FROM at_raw_picks`
- **Verify:** `SELECT COUNT(*) FROM at_raw_picks_bkp_20250320_1430` matches `SELECT COUNT(*) FROM at_raw_picks`

### 2. Dry-Run / Row-Count Preflight (in workflow)
- **Step 5 preflight:** `SELECT COUNT(*) FROM at_raw_picks WHERE symbol LIKE '%=X' OR symbol LIKE '%=F' OR symbol REGEXP '^[^A-Z]'` → report count (should be ~2086)
- **Step 6 preflight:** `SELECT COUNT(*) FROM at_raw_picks WHERE symbol_clean IS NULL` (or whatever re-resolve condition)
- **Step 7 preflight:** `SELECT COUNT(*) FROM alpha_engine_picks WHERE outcome IS NULL` (pending picks)

### 3. Transaction + Post-Write Verification
- **Steps 5-6 in one transaction** (if MySQL supports DDL/DML in transactions):
  ```sql
  START TRANSACTION;
  -- Step 5 UPDATE
  UPDATE at_raw_picks SET symbol = ... WHERE ...;
  -- Step 6 re-resolve (UPDATE/INSERT)
  ...
  COMMIT;
  ```
- **Post-verify:** `SELECT COUNT(*) FROM at_raw_picks WHERE symbol LIKE '%=X'` → should be 0
- **Step 7 separate** (no transaction needed — it's a script flag)

### 4. Rollback Path
- **If steps 5-6 fail:** `RENAME TABLE at_raw_picks TO at_raw_picks_failed, at_raw_picks_bkp_* TO at_raw_picks;`
- **If step 7 fails:** No rollback needed (outcomes are idempotent); re-run with `--apply` again

### 5. Workflow Separation
**Steps 5-6 in ONE workflow** (atomic, gated by typed confirmation):
```yaml
on:
  workflow_dispatch:
    inputs:
      confirm:
        description: 'Type "EXECUTE-NORMALIZE" to proceed'
        required: true
```

**Step 7 in SEPARATE workflow** (lower risk, can be re-run independently):
```yaml
on:
  workflow_dispatch:
    inputs:
      confirm:
        description: 'Type "APPLY-OUTCOMES" to proceed'
        required: true
```

**Why separate:** If step 7 fails mid-way, you don't want to re-trigger steps 5-6. Also allows independent verification of normalization before applying outcomes.
