How System A (The Filter) Works — Plain English

What it does: System A is a gatekeeper. When other strategies generate a "BUY" or "SELL" signal, System A's XGBoost model decides whether to let it through or block it. Think of it like a spam filter for trading signals — only high-quality signals get approved.

What is XGBoost? XGBoost (Extreme Gradient Boosting) is like building a team of 150 simple decision-makers, one at a time. Each new decision-maker focuses on fixing the mistakes of the ones before it. After 150 rounds, the team is very accurate. It's one of the most popular ML algorithms in finance because it handles messy, real-world data well.

How picks appear here: Every 15 minutes, strategy signals come in → System A's XGBoost scores each one (0-100% confidence) → signals above the confidence threshold become picks → TP/SL levels are set based on ATR (volatility).

Current status: DORMANT — System A was disabled because it was underperforming (filtering too aggressively, blocking good signals). It needs retraining with better features.
