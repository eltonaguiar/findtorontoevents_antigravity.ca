## Security (read first)

If a **GitHub PAT** was shared in email or chat, treat it as **compromised**: revoke it under GitHub → Settings → Developer settings → Personal access tokens, then create a new token. Store secrets only in `.env` (gitignored), Git Credential Manager, or `GH_TOKEN` in a **local** shell — never in the repo or plaintext messages.
