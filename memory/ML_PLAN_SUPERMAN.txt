# Key Action Items for Improving Win‑Rate, Profit‑to‑Risk, and ML Quality

## 1. Clean & Validate Features
- **Audit & remove dead/constant features** – see [`feature_defs.py`](alpha_engine/feature_defs.py:1) and the generated audit report [`feature_audit_report.json`](memory/feature_audit_report.json:1).
- **Enforce feature contract** – load [`feature_contract.json`](alpha_engine/feature_contract.json:1) in `forward_validator.py` to abort training if > 50 % dead features.
- **Dynamic schema** – auto‑generate `features_schema.json` via `generate_feature_schema.py` and validate incoming payloads.

## 2. Temporal & Regime Features
- **Time‑of‑day features** (`hour_of_day`, `is_session_start`, `session_duration`) added in [`time_features.py`](alpha_engine/time_features.py:1).
- **Volatility regime classification** (`low`, `medium`, `high`) in [`volatility_features.py`](alpha_engine/volatility_features.py:1) with K‑means.
- **Regime‑specific weights** applied in [`regime_weights.py`](alpha_engine/regime_weights.py:1).

## 3. Entry Timing Scoring
- **Pre‑entry quality model** (`entry_quality`) implemented in [`entry_timing_scoring.py`](alpha_engine/entry_timing_scoring.py:1) using LightGBM.
- **Dynamic threshold** – rolling 30‑day 75th percentile of `entry_quality`.
- **Regime‑interaction matrix** – `regime_interactions.csv` (stored in `memory/`), used to adjust scores.

## 4. Adaptive Stop‑Loss Calibration
- **Extended SL calibrator** – `sl_calibrator.py` now consumes `entry_quality` and uses `sl_calibration_grid.pkl` for regime‑aware SL/TP.
- **Safety buffer** – minimum SL = 0.5 × ATR_1h enforced in `forward_validator.py`.

## 5. Continuous Learning & Monitoring
- **Daily health report** – `feature_health_report.py` writes `feature_health_report.json` (see `memory/feature_health_report.json`).
- **Auto‑retrain trigger** – GitHub Action reads the health report and retrains when dead‑feature % > 30 %.
- **Model drift detection** – `detect_drift.py` compares feature importance distributions; alerts on KL‑divergence > 0.2.

## 6. Infrastructure & Ops
- **Docker container** – `Dockerfile` at repo root ensures reproducible environment.
- **Dashboard enhancements** – `grade_dashboard.html` now shows feature health gauges, regime win‑rate heatmap, and SL calibration MAE/MFE.
- **Slack alerts** – configured via `SLACK_WEBHOOK_URL` for gate blocks > 20 % and health‑gate aborts.

---
**Impact on Win‑Rate / Profit‑to‑Risk**
- Removing dead features and enforcing a live‑only contract reduces noise, directly improving signal precision.
- Regime‑aware weighting and entry‑quality scoring prioritize high‑probability trades, raising win‑rate.
- Adaptive SL calibrated per regime and entry quality tightens risk, improving profit‑to‑risk.
- Continuous health monitoring ensures the model stays current, preventing performance decay.
