## Gotchas learned (for future-me)
- **Yahoo ER unit trap:** `netExpenseRatio` is a PERCENT number (SCHB 0.03 = 0.03%),
  `expenseRatio`/`annualReportExpenseRatio` are FRACTIONS (AGTHX 0.0059 = 0.59%). Treating
  all as fractions charged funds 100× fees → manufactured fake −24%/yr backtest results.
  Normalized + >5% sanity clamp in the fetch. Always verify unit semantics per field.
- pf_registry `is_single_source_artifact` = single_source_pct==1.0 → flags EVERY strategy
  cohort (a strategy has one emitter by definition). Don't use it as the only filter.
- `datetime.utcnow()` deprecation warnings in the tool — cosmetic, not fixed.
- FZLFX + SPLG fetch returned EMPTY from yfinance (skipped, noted in universe JSON).
