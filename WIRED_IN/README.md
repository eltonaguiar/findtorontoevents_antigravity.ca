# WIRED_IN — submitted work, one dated folder per worktree

Every submission in this folder answers the same four questions:

1. **Algorithm specification per asset class** — exact rules, parameters, sizing, costs, benchmark.
2. **Pick justification** — what is recommended, and why that and not the alternative.
3. **What was backtested and/or researched** — data, method, sample, results, with artifacts.
4. **How the alternatives were eliminated** — the gate each one failed.

## Convention

- **Additive only.** A submission may add files under its own dated folder; it does not rewrite another worktree's folder.
- **Numbers must be reproducible** from an artifact shipped in the same folder (or a committed script), or be labelled as arithmetic/estimate.
- **A well-evidenced NO is a valid submission.** Most of what follows is elimination.
