1. Strings

Strings are immutable. Every method below returns a new string; none of them change the original.

Iterate

for...in over an array is a bug. It yields string indices ("0", "1"), skips holes, and picks up anything added to Array.prototype. Always for...of.

3. Objects

Create & access

const o = { a: 1, b: 2 };              // literal
const key = 'c';
const p = { a: 1, [key]: 3, m() { return 1; } }; // computed key + shorthand method
const a = o.a;                          // dot

const own = Object.hasOwn(o, 'a');      // ES2022 — own properties only

Iterate

Destructuring

const { a, b = 2 } = o;              // default when undefined
const { a: first } = o;               // rename a -> first
const { c: { nested } } = o;          // nested path (o.c.nested)
const { d, ...rest } = o;             // rest - everything else
const [x, y] = arr;                   // array destructuring
const [, second] = arr;               // skip an element
const [[h]] = nestedArr;              // nested array
Defaults only fire on undefined, not on null. const { a = 1 } = { a: null } gives a === null. Use ?? if you also want null to fall back.

5. Functions & scope

function hoisted(a, b = 1) { return a + b; }  // declaration + default param
const f = function (x) { return x * 2; };       // expression
const g = x => x * 2;                          // arrow, implicit return
const h = (x, y) => ({ sum: x + y });          // object literal needs parens
function variadic(...args) { return args.length; }  // rest
function memo(fn) {                            // classic closure + Map
  const cache = new Map();
  return n => cache.has(n) ? cache.get(n)
                           : (cache.set(n, fn(n)), cache.get(n));
}
ConceptWhat matters
HoistingFunction declarations hoist and can be called before the line. let/const do not — using them before the declaration throws a ReferenceError (temporal dead zone).
thisArrow functions inherit this from the enclosing scope and have none of their own — which is why they are wrong as methods.
Borrowingfn.call(thisArg, a) · fn.apply(thisArg, [a]) · const b = fn.bind(thisArg).
ClosureA function remembers the scope it was created in. The basis of memoisation, counters and module privacy.
RecursionAlways define the base case first. Deep recursion can hit the call-stack limit (~10k frames) — convert to a loop for large n.
Higher-orderFunctions returning functions: curry, compose, and every map/filter/reduce callback.
Generatorsfunction* gen() { yield x; } — lazily produces values; for (const v of gen()). Useful for huge or infinite sequences.

Set & Map gotchas

Map vs plain object for lookup tables. A Map has guaranteed insertion order, an O(1) .size, no Object.prototype keys to collide with (count['constructor']), and accepts non-string keys. A plain object wins when you need JSON.stringify.

8. Promises & async/await

Barely needed for LeetCode, but part of the essentials.

const p = new Promise((resolve, reject) => { ok ? resolve(v) : reject(e); });
p.then(v => v * 2).catch(e => 0).finally(() => cleanup());

async function f(n) {
  try {
    const a = await fetchThing(n);     // pauses f, not the runtime
    return a;
  } catch (e) {
    return 0;                          // await rethrows, so try/catch works
  }
}
const [a, b] = await Promise.all([x(), y()]);   // parallel, all-or-throw
const r = await Promise.allSettled([x(), y()]); // parallel, never throws
Await is sequential. Two awaits back to back run one after the other — roughly twice as slow as starting both and awaiting both. Use Promise.all for parallel work.

9. Key logic patterns

Each snippet uses only methods documented above.

Two pointers — sorted pair sum

function pairSum(nums, target) {
  let l = 0, r = nums.length - 1;
  while (l < r) {
    const sum = nums[l] + nums[r];
    if (sum === target) return [l, r];
    if (sum < target) l++; else r--;
  }
  return [];
}

Sliding window — longest substring without repeats

function longestUnique(s) {
  const seen = new Set();
  let l = 0, best = 0;
  for (let r = 0; r < s.length; r++) {
    while (seen.has(s[r])) { seen.delete(s[l]); l++; }
    seen.add(s[r]);
    best = Math.max(best, r - l + 1);
  }
  return best;
}

This indexes by code unit (s[r]), matching how JavaScript and LeetCode's JS judge treat strings — so longestUnique('😀😀ab') returns 4, not the 3 you would get counting code points. Convert with [...s] first if the problem means characters.

Frequency map — group anagrams

function groupAnagrams(words) {
  const groups = new Map();
  for (const w of words) {
    const key = [...w].sort().join('');
    groups.set(key, (groups.get(key) ?? []).concat(w));
  }
  return [...groups.values()];
}

Binary search — first index at or after a target

function lowerBound(nums, target) {
  let lo = 0, hi = nums.length;
  while (lo < hi) {
    const mid = (lo + hi) >> 1;        // floor divide by 2, no overflow
    if (nums[mid] < target) lo = mid + 1; else hi = mid;
  }
  return lo;
}

Stack — valid parentheses

function validParens(s) {
  const pairs = { ')': '(', ']': '[', '}': '{' };
  const stack = [];
  for (const c of s) {
    if (c === '(' || c === '[' || c === '{') { stack.push(c); continue; }
    if (stack.pop() !== pairs[c]) return false;
  }
  return stack.length === 0;
}

Prefix sum / Kadane — maximum subarray

function maxSubArray(nums) {
  let best = nums[0], run = nums[0];
  for (let i = 1; i < nums.length; i++) {
    run = Math.max(nums[i], run + nums[i]);
    best = Math.max(best, run);
  }
  return best;
}

Sort with a comparator — top K frequent

function topK(nums, k) {
  const count = {};
  for (const n of nums) count[n] = (count[n] || 0) + 1;
  return Object.entries(count)
    .sort((a, b) => b[1] - a[1])
    .slice(0, k)
    .map(([n]) => Number(n));
}

BFS — shortest path in an unweighted grid

function bfs(start, neighbours) {
  const queue = [start];
  const seen = new Set([start]);
  let steps = 0;
  while (queue.length) {
    const next = [];
    for (const node of queue) {
      for (const nb of neighbours(node)) {
        if (seen.has(nb)) continue;
        seen.add(nb); next.push(nb);
      }
    }
    steps++;
    queue.length = 0;
    for (const n of next) queue.push(n);
  }
  return steps;
}
