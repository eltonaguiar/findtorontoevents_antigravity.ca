# Research artifacts

This folder records how the ITOM field guide was built. It follows an
`AGENT_FOLDERFRAMEWORK`-style protocol: a charter, an isolated research pass, a source matrix,
explicit content decisions, verification, and a merge handoff.

| File | Purpose |
|---|---|
| `00_CHARTER.md` | Scope, success criteria, non-goals, constraints |
| `01_RESEARCH_PLAN.md` | Module matrix, questions, method, timebox |
| `02_SOURCE_MATRIX.md` | Official URL per guide and what was used |
| `03_CONTENT_DECISIONS.md` | Release pinning, naming, corrections, editorial rules |
| `04_VERIFICATION.md` | Lint, link checks, build, deployment, known limitations |
| `05_MERGE_HANDOFF.md` | How to merge into the new ITOM section of the main guide |

These files are **not published** on the GitHub Pages site. They are the evidence trail for the
content and the instructions for the next agent or maintainer.

The machine-readable companions are:

- `data/sources.json` — official source catalog and allowlist
- `data/modules.json` — structured module knowledge base
