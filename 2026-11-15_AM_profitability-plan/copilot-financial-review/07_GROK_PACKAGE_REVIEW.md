## Useful non-peer evidence that changes the diagnosis

Our source coverage establishes that the scheduled prediction-market path primarily emits underlying crypto signals; a token-specific agent is a separate dry-run sidecar. This is a stronger project-specific diagnostic than assuming an external "bots take all profits" explanation. See [the lifecycle analysis](./04_CLAIM_CORRECTIONS_AND_COPYTRADING.md).

Official [TradingView The Leap](https://www.tradingview.com/the-leap/) confirms virtual-money contests. Its October2026commodities champion has43%profitable trades and45.58%contest net profit: a useful caution against making WR>50%a universal theory of profitability, not permission to bypass current production rules.

## QA and handoff

1. Use Grok's prompts as ideas, then append [our common contract](./02_PARALLEL_AGENT_PROMPTS.md) and a single bounded class role.
2. No automatic capital deployment, provider confidence-to-profit conversion or unsupported numerical claims.
3. Verify every benchmark is total-return/date/currency/exposure matched; distinguish raw return from risk improvement.
4. Independently reproduce exact rows/NAV, including unknown, flat, losing and open positions.
5. Preserve existing gates and peer files. The source audit and this review are not a trading authorization.

The current package incorporates these guardrails without changing the peer's published directory.
