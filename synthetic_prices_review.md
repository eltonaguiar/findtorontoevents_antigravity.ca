# Code Review: Places Causing Synthetic Prices\n\n## Executive Summary\n\nA comprehensive search across the codebase revealed **300+ instances** of data filling operations (`.ffill()`, `.fillna()`, `.bfill()`, `.interpolate()`) that can introduce synthetic values, particularly in price data (OHLCV: open, high, low, close).
