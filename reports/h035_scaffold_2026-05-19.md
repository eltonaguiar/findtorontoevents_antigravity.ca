### The signal (Moskowitz-Ooi-Pedersen 2012)

Time-series momentum across a diversified liquid-futures universe:

- **EQUITY-INDEX futures:** `ES=F` (S&P), `NQ=F` (NASDAQ), `YM=F` (Dow),
  `RTY=F` (R2K)
- **CURRENCY futures:** `6E=F` (EUR), `6B=F` (GBP), `6J=F` (JPY), `6A=F` (AUD)
- **COMMODITY futures:** `CL=F` (WTI), `GC=F` (gold), `HG=F` (copper)
- **BOND futures:** `ZN=F` (10Y), `ZB=F` (30Y)

Signal: the SIGN of each contract's trailing 12-month total return. LONG when
positive, SHORT when negative. Each leg is vol-scaled to a target ~10%
annualised volatility (realised over the trailing 60 days, strictly past),
then the diversified book is equal-weighted. Rebalance monthly is the
classical MOP variant; daily rebalance is the harness-density variant.

- `trailing_ret(D)` = `close(D)/close(D-252) - 1` (12 months ≈ 252 trading days)
- `direction(D)` = `sign(trailing_ret(D))` → LONG / SHORT / skip
- `weight(D)` = `min(0.10 / realised_vol_60d(D), 5.0)` — vol-target, capped
- `signal_z` (harness score field) = `|z-score of trailing_ret(D) vs its own
  60-obs strictly-past distribution|` — the CONVICTION MAGNITUDE the harness
  ranks on (the binary sign alone carries no magnitude).
- entry close(D), exit close(D+1), strict no-look-ahead.

**Causal mechanism:** Moskowitz, Ooi & Pedersen 2012 documented the TSMOM
premium across 58 contracts spanning equities, FX, commodities, bonds
(1985-2009). The premium is consistent with under-reaction to information and
delayed over-reaction by uninformed momentum traders. The diversification
across uncorrelated futures classes is the moat — a single-class TSMOM book
is noisier. A sound prior is **NOT** an edge.

### Construction (legitimate density pattern from H-008/H-019/H-026/H-027/H-028)

- **FULL continuous-position diversified book** — one resolved record per
  `(contract, day)` on the daily-rebalance variant. NO sparse event filter,
  NO threshold. The daily variant is what feeds the harness; the classical
  monthly-rebalance MOP book is computed for descriptive context only
  (monthly records are too sparse for the 14-day harness window — ~0.6
  records/day across 13 contracts × ~21 trading days/month).
- **Vol-scaling per leg** — weight = `TARGET_VOL / realised_vol_60d`, capped
  at 5x. The record stores `weight` and
  `signed_ret = raw_ret * direction * weight`.
- **Strict no-look-ahead** — trailing return and realised vol use prices
  STRICTLY at or before day D; position entered at close(D), exited at
  close(D+1). The 60-obs z-score baseline excludes D.

### Data sources — free only

- **PRIMARY (verdict input):** yfinance `=F` continuous-front-month tickers
  (free, no key). ~25-30 years of daily history on the major contracts.
- **OPTIONAL SANITY CHECK:** AQR Capital Management publishes the academic
  monthly Time-Series Momentum factor return series for free at
  <https://www.aqr.com/Insights/Datasets/Time-Series-Momentum-Factors-Monthly>.
  Download the Excel workbook and drop it at
  `tools/cache/aqr_tsmom_monthly.xlsx` (or convert to a 2-column CSV at
  `tools/cache/aqr_tsmom_monthly.csv`). When present, the module loads it
  and reports the published monthly return series alongside the
  reconstruction. The Claude swarm verdict (2026-05-19) was explicit:
  *"AQR publishes factor returns but NOT constituent positions. You need to
  reimplement using yfinance =F tickers."* So the yfinance reconstruction
  **IS** the real implementation; AQR is a smell-test, not the verdict input.

No paid feed, no API key. If yfinance fails the module degrades to a clearly-
labelled synthetic series and reports `UNTESTED-data-gap` — never a
fabricated pass.

## How to run it

```bash
# full run (13 contracts across equity / FX / commodity / bond) — writes the report
python tools/h035_futures_tsmom_research.py

# fast smoke (5 contracts: ES=F, NQ=F, CL=F, GC=F, ZN=F)
python tools/h035_futures_tsmom_research.py --quick

# machine-readable verdict only
python tools/h035_futures_tsmom_research.py --json

# re-fetch yfinance, ignoring the cache
python tools/h035_futures_tsmom_research.py --refresh-cache
```

Output report: `reports/h035_futures_tsmom_research_2026-05-19.md`.
Data cache: `tools/cache/h035_futures_tsmom_cache.json`.
Optional AQR sanity cache: `tools/cache/aqr_tsmom_monthly.{csv,xlsx}`.

The verdict is one of `ADMISSIBLE`, `REJECTED`, or `UNTESTED-data-gap`. A
gaudy in-sample WR is NOT a pass — only the harness + post-cost verdict
counts.

**Known caveats:**

- The monthly-rebalance MOP variant is too sparse for the harness (14-day
  windows × ~0.6 records/day). The daily-rebalance variant is the harness-
  input book; the monthly variant is reported as descriptive context.
- TSMOM has been mined for decades. A pass on this sample is necessary but
  not sufficient — a deflated-Sharpe / SPA multiple-testing correction is
  required before any wiring claim.
- The published TSMOM premium has been criticised as decaying since the GFC.
  A pass should be cross-checked against the post-2010 sub-period separately.

## Wiring Plan

H-035 is an **opt-in sidecar today** and stays that way until it clears the
harness gate. Per the CLAUDE.md Wire-Up Rule, here is the explicit wire-up
path:

- **Target caller file:** `audit_trail/quality_gates.py`
- **Target function:** `passes_active_gate(...)` — the production pick gate.
  H-035 would contribute a `futures_tsmom_long_short` boolean +
  `tsmom_signal_z` feature read by the gate for FUTURES-class picks (and
  surface in `audit_trail/dashboard_generator.py::calculate_smart_score` as
  a scoring input for futures contracts).
- **Pre-wire-up harness-gate condition (HARD GATE — all must hold):**
  1. `tools/h035_futures_tsmom_research.py` must report
     `VERDICT: ADMISSIBLE` — `tools/edge_stability_harness.py::is_admissible()`
     returns `True`: `|eff| >= 0.30`, **same sign**, in `>= 3 of 5` walk-
     forward 14-day windows, each window `>= 80` records.
  2. The post-cost gate must PASS — net edge retains `>= 60%` of gross after
     a 10bps round-trip across the diversified book.
  3. The run must NOT be on a synthetic/offline fallback series — it must
     use the live yfinance `=F` continuous-front tape.
  4. A fresh **out-of-sample** re-test on data collected after the
     `data_sample_lock` must also clear (1)+(2). TSMOM is one of the most-
     mined factors in academic finance — multiple-testing correction is
     mandatory before any production wiring.
  5. **Sub-period robustness:** the harness verdict must hold separately on
     the post-2010 sub-sample (the published TSMOM premium has been
     criticised as decaying since the GFC). A full-sample pass that fails
     post-2010 is rejected.
  6. A deflated-Sharpe / SPA multiple-testing correction and operator sign-
     off.
- **If any condition fails:** archive the H-035 config, mark the registry
  row `REJECTED`, record the `next_step`, and **do NOT re-test the same
  construction on the same sample** (M-107). No wiring.

Until (1)-(6) all hold, H-035 has **zero production callers** and changes
**zero production behaviour**.
