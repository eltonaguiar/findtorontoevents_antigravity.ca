## 1. Overview & Goals

### 1.1 Problem Statement

The findtorontoevents_antigravity.ca quantitative trading platform generates thousands of picks daily across seven asset classes. Each pick passes through a multi-stage quality gate system before becoming an active trading signal. Currently, once a pick is filtered (rejected), it disappears from the system with no persistent record. This creates critical blind spots:

- **No filter forensics:** We cannot reconstruct why a specific pick was rejected
- **No false-negative detection:** We cannot measure how many filtered picks would have been profitable (type II error)
- **No lifecycle visibility:** The journey from scan → filter → active → close is not observable as a single trace
- **No symbol universe governance:** Symbols enter and exit universes without audit trails
- **No strategy attribution:** We cannot attribute P&L back to the original scan source and filtering decisions

### 1.2 Goals

| Goal ID | Goal | Priority | Success Metric |
|---------|------|----------|---------------|
| G1 | Capture every pick scanned, regardless of filtering outcome | P0 | 100% of scanned picks logged within 50ms |
| G2 | Reconstruct complete pick lifecycle (scan → filter → active → close) | P0 | <100ms traceback query latency |
| G3 | Record every filter event with reason, rule ID, and context | P0 | 100% of filtered picks have traceable reason |
| G4 | Enable "what-if" simulation on filtered picks | P1 | Simulate 10,000 picks in <5 seconds |
| G5 | Manage symbol universe per asset class with full history | P1 | Universe changes auditable to the minute |
| G6 | Provide analytics on filter efficiency and false-positive rates | P1 | Daily automated filter-efficiency report |
| G7 | Zero breaking changes to existing trading pipeline | P0 | 0 production incidents attributable to traceability system |

### 1.3 Scope

**In Scope:**
- Pick lifecycle logging (all stages)
- Filter event logging with full context
- Symbol universe registry and history
- What-if simulation engine for filtered picks
- REST API for querying traceability data
- Analytics dashboard for filter efficiency
- Integration with existing `quality_gates.py`, `score_booster.py`, `dashboard_generator.py`

**Out of Scope:**
- Modification of existing scoring logic
- Real-time alerting (covered by existing alerting system)
- ML-based filter optimization
- Multi-region replication

### 1.5 Definitions

| Term | Definition |
|------|-----------|
| **Pick** | A potential trading signal generated by a source system, containing symbol, strategy, direction, and metadata |
| **Quality Gate** | A filtering stage that evaluates a pick against a rule set (e.g., blocked symbol check, confidence threshold) |
| **Filter Event** | A record that a pick was rejected at a specific quality gate with a specific reason |
| **Lifecycle Stage** | One of: `scanned`, `filtered`, `scored`, `active`, `closed`, `expired` |
| **Symbol Universe** | The set of symbols approved for trading within a specific asset class |
| **What-If Simulation** | A hypothetical re-evaluation of a filtered pick as if it had been allowed through |
| **Traceback** | The complete reconstruction of a pick's journey through all quality gates |

## 2. User Stories

### 2.1 Portfolio Manager — Active Pick Visibility

> **As a** portfolio manager,  
> **I want to** see all active picks with the complete reasoning chain (why was this pick selected?),  
> **So that** I can understand the conviction level and risk profile of each active position.

**Acceptance Criteria:**
- [ ] PM can view a table of all active picks with symbol, strategy, direction, confidence score, and entry timestamp
- [ ] Each pick shows the complete gate-pass history (which gates it passed and with what scores)
- [ ] PM can click into any pick to see its full lifecycle trace
- [ ] Data updates within 5 seconds of a pick becoming active
- [ ] Filters available: asset class, strategy, symbol, confidence range, date range

**API Endpoint:** `GET /api/picks?status=active`

---

### 2.2 Risk Manager — Closed Pick P&L Attribution

> **As a** risk manager,  
> **I want to** see all closed picks with P&L attribution linked to their full lifecycle,  
> **So that** I can verify that the trading edge is real and not a data artifact.

**Acceptance Criteria:**
- [ ] Risk manager can view closed picks with realized P&L, holding period, and exit reason
- [ ] Each closed pick links back to its original scan source and all gate decisions
- [ ] P&L can be aggregated by: strategy, asset class, source system, confidence tier
- [ ] Risk manager can compare actual P&L vs. confidence score to validate calibration
- [ ] Export to CSV for external risk reporting

**API Endpoint:** `GET /api/picks?status=closed`

---

### 2.3 Quant Researcher — Filtered Pick Analysis

> **As a** quant researcher,  
> **I want to** see all filtered-out picks with the exact filter reasons,  
> **So that** I can identify overly aggressive filters that may be suppressing alpha.

**Acceptance Criteria:**
- [ ] Researcher can query all filtered picks with exact filter reason codes
- [ ] Filter reasons include: which rule triggered, the rule parameters, and the pick's values at evaluation time
- [ ] Can filter by: specific filter rule, asset class, strategy, symbol, date range
- [ ] Can group by filter reason to see distribution of rejections
- [ ] Results include the pick's raw score before filtering (to assess quality of rejected picks)

**API Endpoint:** `GET /api/picks?status=filtered`

---

### 2.4 System Operator — Symbol Universe Management

> **As a** system operator,  
> **I want to** see the symbol universe per asset class with full history of additions/removals,  
> **So that** I can verify coverage and audit why symbols were added or removed.

**Acceptance Criteria:**
- [ ] Operator can view current symbol universe for any asset class
- [ ] Each symbol shows: added date, added reason, removed date (if applicable), remove reason
- [ ] Operator can search symbol history across all asset classes
- [ ] Changes to the universe are logged with timestamp, operator ID, and reason
- [ ] Can compare universe composition across two dates

**API Endpoint:** `GET /api/symbol-universe?asset_class=ETF`

---

### 2.5 Quant Researcher — What-If Simulation

> **As a** quant researcher,  
> **I want to** run "what-if" analysis on filtered picks ("this pick was filtered due to banned symbol/strategy... but what if it was profitable?"),  
> **So that** I can measure the false-negative rate of our filters and identify alpha leakage.

**Acceptance Criteria:**
- [ ] Researcher can select any filtered pick and simulate "allow" scenario
- [ ] Simulation computes hypothetical P&L based on actual market data from pick timestamp
- [ ] Bulk simulation: can run on all picks filtered by a specific rule over a date range
- [ ] Results show: count of simulated picks, profitable count, avg P&L, max P&L, Sharpe of simulated portfolio
- [ ] Comparison view: actual active picks P&L vs. simulated filtered picks P&L

**API Endpoint:** `POST /api/what-if/simulate`

### 4.2 Data Flow: Scan → Filter → Log → Active → Close

```
Stage 1: SCAN
-------------
[Scanner] → generates PickEvent
    |
    |--> PickLifecycleLogger.log_scan(pick_event)
    |       INSERT INTO pick_lifecycle_log (current_stage='scanned')
    |
    v

Stage 2: QUALITY GATES
----------------------
[quality_gates.py] → evaluates pick against gates sequentially
    |
    |--> Gate 1: format_validation
    |   |-- PASS --> continue
    |   |-- FAIL --> FilterTracebackEngine.log_filter(pick_id, gate_1, reason)
    |                  INSERT INTO filter_event_log (gate_name, rule_id, reason)
    |                  UPDATE pick_lifecycle_log SET current_stage='filtered'
    |                  STOP (pick dies)
    |
    |--> Gate 2: symbol_blocklist (BLOCKED_SYMBOLS)
    |   |-- PASS --> continue
    |   |-- FAIL --> log_filter(...) → pick dies
    |
    |--> Gate 3: strategy_blocklist (BLOCKED_STRATEGIES)
    |   |-- PASS --> continue
    |   |-- FAIL --> log_filter(...) → pick dies
    |
    |--> Gate 4: asset_strategy_pairs (BLOCKED_ASSET_STRATEGY_PAIRS)
    |   |-- PASS --> continue
    |   |-- FAIL --> log_filter(...) → pick dies
    |
    |--> Gate 5: asset_strategy_symbol_triples
    |   |-- PASS --> continue
    |   |-- FAIL --> log_filter(...) → pick dies
    |
    |--> Gate 6: direction_triples (BLOCKED_DIRECTION_TRIPLES)
    |   |-- PASS --> continue
    |   |-- FAIL --> log_filter(...) → pick dies
    |
    |--> Gate 7: confidence_threshold
    |   |-- PASS --> continue
    |   |-- FAIL --> log_filter(...) → pick dies
    |
    v

Stage 3: SCORING (for picks that pass all gates)
------------------------------------------------
[score_booster.py] → applies confidence scoring, regime gates, tier gates
    |
    |--> PickLifecycleLogger.log_gate_pass(pick_id, 'score_booster', score)
    |       INSERT INTO gate_pass_log (gate_name='score_booster', score_at_gate)
    |
    |--> UPDATE pick_lifecycle_log SET current_stage='scored', confidence={score}
    |
    v

Stage 4: ACTIVATION
-------------------
[Activation Logic] → pick becomes active trading signal
    |
    |--> UPDATE pick_lifecycle_log SET current_stage='active', entry_price={price}
    |
    v

Stage 5: CLOSURE
----------------
[Position Manager] → position closes (target, stop, expiry, manual)
    |
    |--> PickLifecycleLogger.log_close(pick_id, exit_price, pnl_pct, exit_reason)
    |       UPDATE pick_lifecycle_log
    |       SET current_stage='closed',
    |           exit_price={price},
    |           pnl_pct={pnl},
    |           stage_timestamp=NOW()
    |
    |--> WhatIfSimulator.post_hoc_update(pick_id)
    |       For all filter_event_log with same symbol/strategy/direction/date:
    |       UPDATE filter_event_log
    |       SET would_have_been_profitable = (simulated_pnl > 0),
    |           hypothetical_pnl_pct = {computed_pnl}
    |
    v
    [End of lifecycle]
```

### 4.3 Integration Points

#### 4.3.1 quality_gates.py Integration

```python
# Current (existing) code pattern:
def evaluate_quality_gates(pick: Pick) -> bool:
    if pick.symbol in BLOCKED_SYMBOLS:
        return False
    if pick.strategy in BLOCKED_STRATEGIES:
        return False
    # ... etc
    return True

# New integration (decorator pattern):
from pick_lifecycle_logger import PickLifecycleLogger
from filter_traceback_engine import FilterTracebackEngine

logger = PickLifecycleLogger.get_instance()
tracer = FilterTracebackEngine.get_instance()

def traceable_gate(gate_name: str, rule_id: str):
    """Decorator that adds traceability to any quality gate check."""
    def decorator(func):
        def wrapper(pick: Pick, *args, **kwargs):
            result = func(pick, *args, **kwargs)
            if not result:
                # Log the filter event
                tracer.log_filter(
                    pick_id=pick.pick_id,
                    gate_name=gate_name,
                    rule_id=rule_id,
                    reason=f"{gate_name}: {pick.symbol}/{pick.strategy}/{pick.direction} failed rule {rule_id}",
                    context={
                        "blocked_set_name": gate_name,
                        "pick_values": pick.to_dict()
                    }
                )
                logger.transition_stage(pick.pick_id, "filtered")
            else:
                # Log successful gate pass
                logger.log_gate_pass(pick_id=pick.pick_id, gate_name=gate_name)
            return result
        return wrapper
    return decorator

# Applied to existing gate functions:
@traceable_gate("symbol_blocklist", "RULE-BLOCK-001")
def check_symbol_blocklist(pick: Pick) -> bool:
    return pick.symbol not in BLOCKED_SYMBOLS

@traceable_gate("strategy_blocklist", "RULE-BLOCK-002")
def check_strategy_blocklist(pick: Pick) -> bool:
    return pick.strategy not in BLOCKED_STRATEGIES

@traceable_gate("asset_strategy_pairs", "RULE-BLOCK-003")
def check_asset_strategy_pairs(pick: Pick) -> bool:
    return (pick.asset_class, pick.strategy) not in BLOCKED_ASSET_STRATEGY_PAIRS

@traceable_gate("asset_strategy_symbol_triples", "RULE-BLOCK-004")
def check_asset_strategy_symbol_triples(pick: Pick) -> bool:
    return (pick.asset_class, pick.strategy, pick.symbol) not in BLOCKED_ASSET_STRATEGY_SYMBOL_TRIPLES

@traceable_gate("direction_triples", "RULE-BLOCK-005")
def check_direction_triples(pick: Pick) -> bool:
    return (pick.asset_class, pick.strategy, pick.direction) not in BLOCKED_DIRECTION_TRIPLES

@traceable_gate("source_system_blocklist", "RULE-BLOCK-006")
```

## 6. Core Modules Design

### 6.1 pick_lifecycle_logger.py

**Purpose:** Singleton logger that captures every pick lifecycle transition.

```python
"""
pick_lifecycle_logger.py

Central singleton for logging pick lifecycle events.
Integrates with quality_gates.py via decorator pattern.
"""

import logging
import threading
from datetime import datetime
from typing import Optional, Dict, Any, List
from dataclasses import dataclass, asdict
import json

from db_connector import get_db_connection  # Existing MySQL connector


@dataclass
class PickEvent:
    """Represents a pick at scan time."""
    pick_id: str
    scan_timestamp: datetime
    symbol: str
    asset_class: str
    strategy: str
    source_system: str
    direction: str
    entry_price: Optional[float] = None
    scan_metadata: Optional[Dict[str, Any]] = None


@dataclass
class GatePassEvent:
    """Records a successful gate pass."""
    pick_id: str
    gate_name: str
    gate_order: int
    score_at_gate: Optional[float] = None
    gate_params: Optional[Dict[str, Any]] = None


@dataclass
class CloseEvent:
    """Records a pick closure."""
    pick_id: str
    exit_price: float
    pnl_pct: float
    exit_reason: str  # 'target_hit', 'stop_loss', 'time_expiry', 'manual'


class PickLifecycleLogger:
    """
    Singleton logger for pick lifecycle events.

    Thread-safe. Uses connection pooling for DB writes.
    All methods are non-blocking (fire-and-forget with async background writer).
    """

    _instance: Optional['PickLifecycleLogger'] = None
    _lock = threading.Lock()

    # Lifecycle stages
    STAGE_SCANNED = 'scanned'
    STAGE_FILTERED = 'filtered'
    STAGE_SCORED = 'scored'
    STAGE_ACTIVE = 'active'
    STAGE_CLOSED = 'closed'
    STAGE_EXPIRED = 'expired'

    def __new__(cls) -> 'PickLifecycleLogger':
        if cls._instance is None:
            with cls._lock:
                if cls._instance is None:
                    cls._instance = super().__new__(cls)
                    cls._instance._initialized = False
        return cls._instance

    def __init__(self):
        if self._initialized:
            return
        self._initialized = True
        self.logger = logging.getLogger('pick_lifecycle')
        self._db_pool = get_db_connection(pool_size=5)
        self._local = threading.local()
        self._batch_queue: List[Dict] = []
        self._batch_lock = threading.Lock()
        self._batch_size = 100
        self._batch_flush_interval_seconds = 5
        self._start_batch_flusher()

    @classmethod
    def get_instance(cls) -> 'PickLifecycleLogger':
        return cls()

    def _start_batch_flusher(self):
        """Start background thread for batch flushing."""
        def flusher():
            while True:
                time.sleep(self._batch_flush_interval_seconds)
                self._flush_batch()
        import time
        thread = threading.Thread(target=flusher, daemon=True)
        thread.start()

    def _flush_batch(self):
        """Flush batched writes to DB."""
        with self._batch_lock:
            if not self._batch_queue:
                return
            batch = self._batch_queue[:]
            self._batch_queue = []
        try:
            conn = self._db_pool.get_connection()
            cursor = conn.cursor()
            for record in batch:
                self._execute_write(cursor, record)
            conn.commit()
            cursor.close()
            conn.close()
        except Exception as e:
            self.logger.error(f"Batch flush failed: {e}")
            # Re-queue for retry
            with self._batch_lock:
                self._batch_queue.extend(batch)

    def _execute_write(self, cursor, record: Dict):
        """Execute a single write operation."""
        operation = record['op']
        if operation == 'insert_pick':
            cursor.execute("""
                INSERT INTO pick_lifecycle_log
                (pick_id, scan_timestamp, symbol, asset_class, strategy,
                 source_system, direction, entry_price, current_stage,
                 stage_timestamp, scan_metadata_json, confidence)
                VALUES (%s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s)
            """, (
                record['pick_id'], record['scan_timestamp'], record['symbol'],
                record['asset_class'], record['strategy'], record['source_system'],
                record['direction'], record['entry_price'], record['current_stage'],
                record['stage_timestamp'], json.dumps(record.get('scan_metadata', {})),
                record.get('confidence')
            ))
        elif operation == 'update_stage':
            cursor.execute("""
                UPDATE pick_lifecycle_log
                SET current_stage = %s, stage_timestamp = %s, updated_at = NOW(3)
                WHERE pick_id = %s
            """, (record['stage'], record['timestamp'], record['pick_id']))
        elif operation == 'update_close':
            cursor.execute("""
                UPDATE pick_lifecycle_log
                SET current_stage = 'closed', exit_price = %s, pnl_pct = %s,
                    stage_timestamp = %s, updated_at = NOW(3)
                WHERE pick_id = %s
            """, (record['exit_price'], record['pnl_pct'], record['timestamp'], record['pick_id']))
        elif operation == 'update_confidence':
            cursor.execute("""
                UPDATE pick_lifecycle_log
                SET confidence = %s, updated_at = NOW(3)
                WHERE pick_id = %s
            """, (record['confidence'], record['pick_id']))

    def _queue_write(self, record: Dict):
        """Queue a write for batch processing."""
        with self._batch_lock:
            self._batch_queue.append(record)
            if len(self._batch_queue) >= self._batch_size:
                # Trigger immediate flush in background
                threading.Thread(target=self._flush_batch, daemon=True).start()

    def log_scan(self, pick_event: PickEvent) -> str:
        """
        Log a new pick scan event.
        Returns the pick_id for reference.
        """
        self._queue_write({
            'op': 'insert_pick',
            'pick_id': pick_event.pick_id,
            'scan_timestamp': pick_event.scan_timestamp,
            'symbol': pick_event.symbol,
            'asset_class': pick_event.asset_class,
            'strategy': pick_event.strategy,
            'source_system': pick_event.source_system,
            'direction': pick_event.direction,
            'entry_price': pick_event.entry_price,
            'current_stage': self.STAGE_SCANNED,
            'stage_timestamp': datetime.utcnow(),
            'scan_metadata': pick_event.scan_metadata
        })
        self.logger.debug(f"Logged scan: {pick_event.pick_id} {pick_event.symbol}")
        return pick_event.pick_id

    def transition_stage(self, pick_id: str, new_stage: str):
        """Transition a pick to a new lifecycle stage."""
        self._queue_write({
            'op': 'update_stage',
            'pick_id': pick_id,
            'stage': new_stage,
            'timestamp': datetime.utcnow()
        })
        self.logger.debug(f"Stage transition: {pick_id} -> {new_stage}")

    def log_gate_pass(self, pick_id: str, gate_name: str,
                      score_at_gate: Optional[float] = None,
                      gate_params: Optional[Dict] = None):
        """Log a successful gate pass."""
        try:

                INSERT INTO gate_pass_log
                (pick_id, gate_name, gate_order, score_at_gate, gate_params_json, passed_at)
                VALUES (%s, %s, %s, %s, %s, NOW(3))
            """, (pick_id, gate_name, self._get_gate_order(gate_name),

            cursor.close()
            conn.close()
        except Exception as e:
            self.logger.error(f"Failed to log gate pass: {e}")

    def update_confidence(self, pick_id: str, confidence: float):
```

```python
class FilterTracebackEngine:
    """
    Singleton engine for filter traceback reconstruction.

    - Logs filter events when picks are rejected
    - Reconstructs complete gate history for any pick
    - Computes post-hoc profitability for filtered picks
    """

    _instance: Optional['FilterTracebackEngine'] = None

    # Rule type mapping
    RULE_TYPES = {
        'RULE-BLOCK': 'BLOCKLIST',
        'RULE-THRESH': 'THRESHOLD',
        'RULE-REGIME': 'REGIME',
        'RULE-TIER': 'TIER',
        'RULE-FMT': 'FORMAT',
        'RULE-CUST': 'CUSTOM'

    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
            cls._instance._initialized = False
        return cls._instance

    def __init__(self):
        if self._initialized:
            return
        self._initialized = True
        self.logger = logging.getLogger('filter_traceback')
        self._db_pool = get_db_connection(pool_size=3)

    @classmethod
    def get_instance(cls) -> 'FilterTracebackEngine':
        return cls()

    def log_filter(self, pick_id: str, gate_name: str, rule_id: str,
                   reason: str, context: Dict[str, Any],
                   pick_values: Optional[Dict[str, Any]] = None):
        """
        Log a filter event when a pick is rejected.

        Called from the @traceable_gate decorator.
        """
        try:
            conn = self._db_pool.get_connection()
            cursor = conn.cursor()

            filter_event_id = f"fev_{pick_id[:8]}_{gate_name}"
            rule_type = self._infer_rule_type(rule_id)

            cursor.execute("""
                INSERT INTO filter_event_log
                (filter_event_id, pick_id, gate_name, rule_id, rule_type,
                 filter_reason, filter_context_json, filter_timestamp,
                 pick_values_at_filter_json)
                VALUES (%s, %s, %s, %s, %s, %s, %s, NOW(3), %s)
            """, (
                filter_event_id, pick_id, gate_name, rule_id, rule_type,
                reason, json.dumps(context), json.dumps(pick_values or {})
            ))
            conn.commit()
            cursor.close()
            conn.close()

            # Transition pick lifecycle stage
            PickLifecycleLogger.get_instance().transition_stage(pick_id, 'filtered')

            self.logger.debug(f"Filter logged: {pick_id} at {gate_name} / {rule_id}")

        except Exception as e:
            self.logger.error(f"Failed to log filter event: {e}")

    def get_traceback(self, pick_id: str) -> Optional[FilterTraceback]:
        """
        Reconstruct the complete traceback for a pick.

        Returns full gate-by-gate evaluation history.
        """
        try:
            conn = self._db_pool.get_connection()
            cursor = conn.cursor(dictionary=True)

            # Get pick lifecycle record
            cursor.execute("""
                SELECT * FROM pick_lifecycle_log WHERE pick_id = %s
            """, (pick_id,))
            pick_row = cursor.fetchone()
            if not pick_row:
                return None

            # Get all gate pass records
            cursor.execute("""
                SELECT * FROM gate_pass_log WHERE pick_id = %s ORDER BY gate_order
            """, (pick_id,))
            gate_passes = cursor.fetchall()

            # Get filter event (if filtered)
            cursor.execute("""
                SELECT * FROM filter_event_log WHERE pick_id = %s
            """, (pick_id,))
            filter_events = cursor.fetchall()

            cursor.close()
            conn.close()

            # Build gate evaluations
            gate_evaluations = []
            for gp in gate_passes:
                gate_evaluations.append({
                    'gate_order': gp['gate_order'],
                    'gate_name': gp['gate_name'],
                    'rule_id': None,  # Pass events don't have rule IDs
                    'result': 'PASSED',
                    'timestamp': gp['passed_at'].isoformat(),
                    'score_at_gate': float(gp['score_at_gate']) if gp['score_at_gate'] else None,
                    'latency_ms': None
                })

            for fe in filter_events:
                gate_evaluations.append({
                    'gate_order': self._get_gate_order(fe['gate_name']),
                    'gate_name': fe['gate_name'],
                    'rule_id': fe['rule_id'],
                    'rule_type': fe['rule_type'],
                    'result': 'FAILED',
                    'timestamp': fe['filter_timestamp'].isoformat(),
                    'filter_details': {
                        'reason': fe['filter_reason'],
                        'context': json.loads(fe['filter_context_json'])
                    }
                })

            # Sort by gate order
            gate_evaluations.sort(key=lambda x: x['gate_order'])

            # Build filter summary
            filter_summary = {}
            if filter_events:
                latest_filter = filter_events[-1]
                filter_summary = {
                    'gate_that_filtered': latest_filter['gate_name'],
                    'rule_that_filtered': latest_filter['rule_id'],
                    'would_have_been_profitable': latest_filter['would_have_been_profitable'],
                    'hypothetical_pnl_pct': float(latest_filter['hypothetical_pnl_pct']) if latest_filter['hypothetical_pnl_pct'] else None,
                    'missed_opportunity': latest_filter['would_have_been_profitable'] is True
                }

            return FilterTraceback(
                pick_id=pick_id,
                scan_timestamp=pick_row['scan_timestamp'],
                symbol=pick_row['symbol'],
                asset_class=pick_row['asset_class'],
                strategy=pick_row['strategy'],
                direction=pick_row['direction'],
                final_stage=pick_row['current_stage'],
                total_gates_evaluated=len(gate_evaluations),
                total_latency_ms=sum(
                    (g.get('latency_ms') or 0) for g in gate_evaluations
                ),
                gate_evaluations=gate_evaluations,
                filter_summary=filter_summary
            )

        except Exception as e:
            self.logger.error(f"Traceback reconstruction failed for {pick_id}: {e}")
            return None

    def get_filter_distribution(self, days: int = 7,
                                  asset_class: Optional[str] = None) -> Dict[str, int]:
        """Get distribution of filter reasons over a time period."""
        try:
            conn = self._db_pool.get_connection()

                SELECT gate_name, COUNT(*) as cnt
                FROM filter_event_log
                WHERE filter_timestamp >= DATE_SUB(NOW(), INTERVAL %s DAY)
            """
            params = [days]
            if asset_class:
                query += " AND asset_class = %s"
                params.append(asset_class)
            query += " GROUP BY gate_name ORDER BY cnt DESC"

            cursor.execute(query, params)
            results = {row[0]: row[1] for row in cursor.fetchall()}
            cursor.close()
            conn.close()
            return results

        except Exception as e:
            self.logger.error(f"Filter distribution query failed: {e}")
            return {}

    def _infer_rule_type(self, rule_id: str) -> str:

            if rule_id.startswith(prefix):
                return rule_type
        return 'CUSTOM'

    def _get_gate_order(self, gate_name: str) -> int:

            'asset_strategy_pairs': 4,
            'asset_strategy_symbol_triples': 5,
            'direction_triples': 6,
            'source_system_blocklist': 7,
            'confidence_threshold': 8,
            'regime_gate': 9,
            'tier_gate': 10
        }
        return orders.get(gate_name, 99)
```

```python
            symbol_id = row['symbol_id']

            raise

            params = []

                where_clauses.append("universe_status = %s")
                params.append(status.value)

                SELECT COUNT(*) as total FROM symbol_universe_registry WHERE {where_str}

                SELECT * FROM symbol_universe_registry
                WHERE {where_str}
                ORDER BY symbol
                LIMIT %s OFFSET %s
            """, params + [page_size, offset])

            return {
                'data': rows,
                'pagination': {
                    'page': page,
                    'page_size': page_size,
                    'total_count': total,
                    'total_pages': (total + page_size - 1) // page_size
                }
            }

        finally:
            cursor.close()
            conn.close()

    def get_symbol_history(self, symbol: str,

                WHERE r.symbol = %s
            """
            params = [symbol]
            if asset_class:
                query += " AND r.asset_class = %s"
                params.append(asset_class.value)
            query += " ORDER BY h.changed_at DESC"

            cursor.execute(query, params)
            return cursor.fetchall()

        finally:
            cursor.close()
            conn.close()
```

```python
    run_name: str
    simulation_type: str  # 'single_pick', 'filter_rule', 'date_range', 'custom'
    filter_rule_id: Optional[str] = None
    date_from: Optional[str] = None
    date_to: Optional[str] = None
    asset_class: Optional[str] = None
    strategy: Optional[str] = None
    hypothetical_action: str = 'allow'
    action_params: Optional[Dict[str, Any]] = None
    sample_size: Optional[int] = None


@dataclass
class SimulationResult:
    """Result for a single pick simulation."""
    pick_id: str
    filter_event_id: str
    simulated_entry_price: float
    simulated_exit_price: float
    simulated_pnl_pct: float
    holding_period_days: int
    profitable: bool
    exit_reason: str
    market_data_points_used: int


class WhatIfSimulator:
    """
    What-If Simulation Engine.

    - Runs bulk simulations on filtered picks
    - Computes hypothetical P&L using historical market data
    - Updates filter_event_log with post-hoc profitability
    - Generates aggregate analytics
    """

    DEFAULT_HOLDING_PERIOD_DAYS = 5
    MAX_WORKERS = 8

    def __init__(self):
        self.logger = logging.getLogger('what_if_simulator')
        self._db_pool = get_db_connection(pool_size=5)
        self._market_data = MarketDataService()
        self._executor = ThreadPoolExecutor(max_workers=self.MAX_WORKERS)

    def create_simulation_run(self, config: SimulationConfig,
                              created_by: str) -> str:
        """
        Create and queue a simulation run.
        Returns run_id.
        """
        run_id = f"run_{uuid.uuid4().hex[:24]}"

        # Estimate picks in scope
        total_picks = self._count_picks_in_scope(config)

        conn = self._db_pool.get_connection()
        cursor = conn.cursor()
        try:
            cursor.execute("""
                INSERT INTO what_if_simulation_run
                (run_id, run_name, simulation_type, filter_rule_id,
                 date_from, date_to, asset_class, strategy,
                 hypothetical_action, action_params_json,
                 status, total_picks, created_by, created_at)
                VALUES (%s, %s, %s, %s, %s, %s, %s, %s, %s, %s, 'pending', %s, %s, NOW(3))
            """, (
                run_id, config.run_name, config.simulation_type,
                config.filter_rule_id, config.date_from, config.date_to,
                config.asset_class, config.strategy,
                config.hypothetical_action,
                json.dumps(config.action_params or {}),
                total_picks, created_by
            ))
            conn.commit()

            # Start simulation in background
            self._executor.submit(self._execute_run, run_id, config)

            return run_id

        finally:
            cursor.close()
            conn.close()

    def _execute_run(self, run_id: str, config: SimulationConfig):
        """Execute a simulation run."""
        conn = self._db_pool.get_connection()
        cursor = conn.cursor(dictionary=True)

        try:
            # Update status to running
            cursor.execute("""
                UPDATE what_if_simulation_run
                SET status = 'running', started_at = NOW(3)
                WHERE run_id = %s
            """, (run_id,))
            conn.commit()

            # Get picks to simulate
            picks = self._get_picks_for_simulation(cursor, config)
            if config.sample_size and len(picks) > config.sample_size:
                picks = picks[:config.sample_size]

            total = len(picks)
            results: List[SimulationResult] = []

            # Simulate each pick
            for i, pick in enumerate(picks):
                result = self._simulate_single_pick(pick, config)
                if result:
                    results.append(result)
                    self._save_result(cursor, run_id, result)

                # Update progress every 100 picks
                if (i + 1) % 100 == 0:
                    cursor.execute("""
                        UPDATE what_if_simulation_run
                        SET processed_picks = %s
                        WHERE run_id = %s
                    """, (i + 1, run_id))
                    conn.commit()

            # Compute and save summary
            summary = self._compute_summary(results)
            cursor.execute("""
                UPDATE what_if_simulation_run
                SET status = 'completed',
                    processed_picks = %s,
                    completed_at = NOW(3),
                    results_summary_json = %s
                WHERE run_id = %s
            """, (total, json.dumps(summary), run_id))
            conn.commit()

            self.logger.info(f"Simulation {run_id} completed: {total} picks processed")

        except Exception as e:
            self.logger.error(f"Simulation {run_id} failed: {e}")
            cursor.execute("""
                UPDATE what_if_simulation_run
                SET status = 'failed', completed_at = NOW(3)
                WHERE run_id = %s
            """, (run_id,))
            conn.commit()

        finally:
            cursor.close()
            conn.close()

    def _simulate_single_pick(self, pick: Dict[str, Any],
                              config: SimulationConfig) -> Optional[SimulationResult]:
        """
        Simulate a single pick as if it had been allowed.

        Uses actual market data from pick timestamp to compute
        hypothetical P&L.
        """
        try:
            symbol = pick['symbol']
            entry_date = pick['filter_timestamp']
            holding_days = (config.action_params or {}).get(
                'holding_period_days', self.DEFAULT_HOLDING_PERIOD_DAYS
            )
            exit_date = entry_date + timedelta(days=holding_days)

            # Get entry price (pick's entry or close price at scan)
            entry_price = pick.get('entry_price')
            if not entry_price:
                entry_price = self._market_data.get_close_price(symbol, entry_date)

            # Get exit price
            exit_price = self._market_data.get_close_price(symbol, exit_date)

            if not entry_price or not exit_price:
                return None

            # Calculate P&L
            direction = pick.get('direction', 'LONG')
            if direction == 'LONG':
                pnl_pct = (exit_price - entry_price) / entry_price
            else:
                pnl_pct = (entry_price - exit_price) / entry_price

            return SimulationResult(
                pick_id=pick['pick_id'],
                filter_event_id=pick['filter_event_id'],
                simulated_entry_price=entry_price,
                simulated_exit_price=exit_price,
                simulated_pnl_pct=pnl_pct,
                holding_period_days=holding_days,
                profitable=pnl_pct > 0,
                exit_reason='time_expiry',
                market_data_points_used=holding_days
            )

        except Exception as e:
            self.logger.error(f"Simulation failed for pick {pick.get('pick_id')}: {e}")
            return None

    def _compute_summary(self, results: List[SimulationResult]) -> Dict[str, Any]:
        """Compute aggregate summary from simulation results."""
        if not results:
            return {"total_simulated": 0}

        pnls = [r.simulated_pnl_pct for r in results]
        profitable = [p for p in pnls if p > 0]
        unprofitable = [p for p in pnls if p <= 0]

        avg_pnl = sum(pnls) / len(pnls)

        # Sharpe (simplified, annualized)
        import statistics
        if len(pnls) > 1:
            std_dev = statistics.stdev(pnls)
            sharpe = (avg_pnl / std_dev) * (252 ** 0.5) if std_dev > 0 else 0
        else:
            sharpe = 0

        return {
            "total_simulated": len(results),
            "profitable_count": len(profitable),
            "unprofitable_count": len(unprofitable),
            "avg_pnl_pct": round(avg_pnl, 6),
            "median_pnl_pct": round(statistics.median(pnls), 6) if pnls else 0,
            "max_pnl_pct": round(max(pnls), 6),
            "min_pnl_pct": round(min(pnls), 6),
            "sharpe_ratio": round(sharpe, 2),
            "win_rate": round(len(profitable) / len(pnls), 4),
            "total_return_pct": round(sum(pnls) * 100, 2)
        }

    def _get_picks_for_simulation(self, cursor,
                                   config: SimulationConfig) -> List[Dict]:
        """Get the list of picks to simulate based on config."""
        query = """
            SELECT f.filter_event_id, f.pick_id, f.filter_timestamp,
                   f.rule_id, p.symbol, p.direction, p.entry_price,
                   p.asset_class, p.strategy
            FROM filter_event_log f
            JOIN pick_lifecycle_log p ON f.pick_id = p.pick_id
            WHERE 1=1
        """
        params = []

        if config.filter_rule_id:
            query += " AND f.rule_id = %s"
            params.append(config.filter_rule_id)
        if config.date_from:
            query += " AND f.filter_timestamp >= %s"
            params.append(config.date_from)
        if config.date_to:
            query += " AND f.filter_timestamp <= %s"
            params.append(config.date_to)
        if config.asset_class:
            query += " AND p.asset_class = %s"
            params.append(config.asset_class)
        if config.strategy:
            query += " AND p.strategy = %s"
            params.append(config.strategy)

        query += " ORDER BY f.filter_timestamp DESC"

        if config.sample_size:
            query += " LIMIT %s"
            params.append(config.sample_size)

        cursor.execute(query, params)
        return cursor.fetchall()

    def _count_picks_in_scope(self, config: SimulationConfig) -> int:
        """Count total picks matching simulation criteria."""
        conn = self._db_pool.get_connection()
        cursor = conn.cursor()
        try:
            query = """
                SELECT COUNT(*) FROM filter_event_log f
                JOIN pick_lifecycle_log p ON f.pick_id = p.pick_id
                WHERE 1=1
            """
            params = []
            if config.filter_rule_id:
                query += " AND f.rule_id = %s"
                params.append(config.filter_rule_id)
            if config.date_from:
                query += " AND f.filter_timestamp >= %s"
                params.append(config.date_from)
            if config.date_to:
                query += " AND f.filter_timestamp <= %s"
                params.append(config.date_to)
            if config.asset_class:
                query += " AND p.asset_class = %s"
                params.append(config.asset_class)

            cursor.execute(query, params)
            return cursor.fetchone()[0]
        finally:
            cursor.close()
            conn.close()

    def _save_result(self, cursor, run_id: str, result: SimulationResult):
        """Save a single simulation result."""
        cursor.execute("""
            INSERT INTO what_if_simulation_result
            (run_id, pick_id, filter_event_id, simulated_entry_price,
             simulated_exit_price, simulated_pnl_pct, holding_period_days,
             exit_reason, created_at)
            VALUES (%s, %s, %s, %s, %s, %s, %s, %s, NOW(3))
        """, (
            run_id, result.pick_id, result.filter_event_id,
            result.simulated_entry_price, result.simulated_exit_price,
            result.simulated_pnl_pct, result.holding_period_days,
            result.exit_reason
        ))

    def post_hoc_update_filtered_picks(self, pick_id: str,
                                        actual_exit_price: float,
                                        actual_pnl_pct: float):
        """
        After a similar pick closes, update filtered picks
        with matching symbol/strategy to estimate what-if P&L.

        This is called by PickLifecycleLogger.log_close() to
        continuously improve false-negative estimates.
        """
        conn = self._db_pool.get_connection()
        cursor = conn.cursor(dictionary=True)

        try:
            # Get the closed pick's details
            cursor.execute("""
                SELECT symbol, strategy, direction, asset_class
                FROM pick_lifecycle_log WHERE pick_id = %s
            """, (pick_id,))
            closed_pick = cursor.fetchone()
            if not closed_pick:
                return

            # Find filtered picks with same symbol/strategy/direction
            # that were filtered in the last 30 days
            cursor.execute("""
                UPDATE filter_event_log f
                JOIN pick_lifecycle_log p ON f.pick_id = p.pick_id
                SET f.would_have_been_profitable = %s,
                    f.hypothetical_pnl_pct = %s
                WHERE p.symbol = %s
                  AND p.strategy = %s
                  AND p.direction = %s
                  AND p.asset_class = %s
                  AND f.would_have_been_profitable IS NULL
                  AND p.scan_timestamp >= DATE_SUB(NOW(), INTERVAL 30 DAY)
            """, (
                actual_pnl_pct > 0,
                actual_pnl_pct,
                closed_pick['symbol'],
                closed_pick['strategy'],
                closed_pick['direction'],
                closed_pick['asset_class']
            ))
            conn.commit()

            affected = cursor.rowcount
            if affected > 0:
                self.logger.info(
                    f"Post-hoc update: {affected} filtered picks updated "
                    f"from closed pick {pick_id}"
                )

        finally:
            cursor.close()
            conn.close()
```

```python
"""
pick_analytics_dashboard.py

Aggregated analytics for the Pick Traceability dashboard.

Provides pre-computed metrics for:
- Filter efficiency (which filters catch the most, false-positive rates)
- Pick volume trends
- P&L attribution by strategy/asset class

import logging
from typing import Dict, Any, List, Optional
from datetime import datetime, timedelta
import json

from db_connector import get_db_connection


class PickAnalyticsDashboard:
    """
    Analytics engine for pick traceability metrics.

    All methods return serializable dicts suitable for dashboard_data.json
    and the React dashboard frontend.
    """

    def __init__(self):
        self.logger = logging.getLogger('pick_analytics')
        self._db_pool = get_db_connection(pool_size=3)

    def get_filter_efficiency(self, date_from: Optional[str] = None,
                               date_to: Optional[str] = None,
                               asset_class: Optional[str] = None,
                               group_by: str = 'gate_name') -> Dict[str, Any]:
        """
        Get filter efficiency analytics.

        Shows for each filter:
        - Total picks caught
        - % of all filters
        - Avg confidence of filtered picks
        - False negative rate (would have been profitable)
        - Estimated alpha leaked
        """
        conn = self._db_pool.get_connection()
        cursor = conn.cursor(dictionary=True)

        try:
            date_from = date_from or (datetime.utcnow() - timedelta(days=30)).strftime('%Y-%m-%d')
            date_to = date_to or datetime.utcnow().strftime('%Y-%m-%d')

            # Summary stats
            cursor.execute("""
                SELECT
                    COUNT(*) as total_scanned,
                    SUM(CASE WHEN current_stage = 'filtered' THEN 1 ELSE 0 END) as total_filtered,
                    SUM(CASE WHEN current_stage = 'active' THEN 1 ELSE 0 END) as total_active,
                    SUM(CASE WHEN current_stage = 'closed' THEN 1 ELSE 0 END) as total_closed
                FROM pick_lifecycle_log
                WHERE scan_timestamp BETWEEN %s AND %s
            """, (date_from, date_to))
            summary = cursor.fetchone()

            # Per-gate stats
            cursor.execute("""
                SELECT
                    f.gate_name,
                    f.rule_id,
                    COUNT(*) as total_filtered,
                    AVG(p.confidence) as avg_confidence_of_filtered,
                    SUM(CASE WHEN f.would_have_been_profitable = TRUE THEN 1 ELSE 0 END) as false_negatives,
                    AVG(CASE WHEN f.would_have_been_profitable = TRUE
                        THEN f.hypothetical_pnl_pct ELSE NULL END) as avg_missed_pnl,
                    AVG(f.hypothetical_pnl_pct) as avg_hypothetical_pnl
                FROM filter_event_log f
                JOIN pick_lifecycle_log p ON f.pick_id = p.pick_id
                WHERE f.filter_timestamp BETWEEN %s AND %s
                GROUP BY f.gate_name, f.rule_id
                ORDER BY total_filtered DESC
            """, (date_from, date_to))
            gate_stats = cursor.fetchall()

            # Format response
            total_filtered = summary['total_filtered'] or 1  # Avoid div by zero
            by_gate = []
            for g in gate_stats:
                false_neg_rate = (
                    g['false_negatives'] / g['total_filtered']
                    if g['total_filtered'] > 0 else 0
                )
                by_gate.append({
                    'gate_name': g['gate_name'],
                    'rule_id': g['rule_id'],
                    'total_filtered': g['total_filtered'],
                    'pct_of_all_filters': round(g['total_filtered'] / total_filtered, 4),
                    'avg_confidence_of_filtered': round(float(g['avg_confidence_of_filtered'] or 0), 4),
                    'false_negatives': g['false_negatives'] or 0,
                    'false_negative_rate': round(false_neg_rate, 4),
                    'avg_missed_pnl_pct': round(float(g['avg_missed_pnl'] or 0), 6),
                    'estimated_alpha_leaked_pct': round(
                        float(g['avg_missed_pnl'] or 0) * (g['false_negatives'] or 0) * 100, 2
                    )
                })

            # Overall false negative rate
            cursor.execute("""
                SELECT
                    COUNT(*) as total_filtered_with_data,
                    SUM(CASE WHEN would_have_been_profitable = TRUE THEN 1 ELSE 0 END) as false_negatives
                FROM filter_event_log
                WHERE filter_timestamp BETWEEN %s AND %s
                  AND would_have_been_profitable IS NOT NULL
            """, (date_from, date_to))
            fn_data = cursor.fetchone()
            overall_fn_rate = (
                fn_data['false_negatives'] / fn_data['total_filtered_with_data']
                if fn_data['total_filtered_with_data'] > 0 else 0
            )

            return {
                'period': {'date_from': date_from, 'date_to': date_to},
                'summary': {
                    'total_scanned': summary['total_scanned'],
                    'total_filtered': summary['total_filtered'],
                    'total_active': summary['total_active'],
                    'total_closed': summary['total_closed'],
                    'filter_rate': round(
                        summary['total_filtered'] / (summary['total_scanned'] or 1), 4
                    ),
                    'overall_false_negative_rate': round(overall_fn_rate, 4)
                },
                'by_gate': by_gate,
                'recommendations': self._generate_recommendations(by_gate),
                'generated_at': datetime.utcnow().isoformat()
            }

        finally:
            cursor.close()
            conn.close()

    def get_pick_volume_timeseries(self, date_from: str, date_to: str,

    def get_pnl_attribution(self, date_from: str, date_to: str) -> Dict[str, Any]:

                    strategy,
                    COUNT(*) as pick_count,

                  AND scan_timestamp BETWEEN %s AND %s

            cursor.execute("""
                SELECT
                    asset_class,
                    COUNT(*) as pick_count,
                    AVG(pnl_pct) as avg_pnl,
                    SUM(pnl_pct) as total_pnl,
                    SUM(CASE WHEN pnl_pct > 0 THEN 1 ELSE 0 END) as winners,
                    SUM(CASE WHEN pnl_pct < 0 THEN 1 ELSE 0 END) as losers
                FROM pick_lifecycle_log
                WHERE current_stage = 'closed'
                  AND scan_timestamp BETWEEN %s AND %s
                GROUP BY asset_class

            """, (date_from, date_to))

            return {
                'by_strategy': by_strategy,
                'by_asset_class': by_asset_class,
                'period': {'date_from': date_from, 'date_to': date_to}
            }

        finally:
            cursor.close()
            conn.close()

    def get_symbol_universe_health(self) -> Dict[str, Any]:

        conn = self._db_pool.get_connection()

                SELECT
                    asset_class,
                    universe_status,
                    COUNT(*) as count
                FROM symbol_universe_registry

            health = {}
            for r in rows:
                ac = r['asset_class']
                if ac not in health:
                    health[ac] = {}
                health[ac][r['universe_status']] = r['count']

            # Recent changes
            cursor.execute("""
                SELECT
                    asset_class,
                    new_status,
                    COUNT(*) as change_count

                WHERE changed_at >= DATE_SUB(NOW(), INTERVAL 7 DAY)

            recent = cursor.fetchall()

            return {
                'current_composition': health,
                'recent_changes_7d': recent,
                'generated_at': datetime.utcnow().isoformat()
            }

        finally:
            cursor.close()
            conn.close()

    def _generate_recommendations(self, by_gate: List[Dict]) -> List[Dict]:
        """Generate filter tuning recommendations."""
        recommendations = []

        for gate in by_gate:
            if gate['false_negative_rate'] > 0.1:  # >10% false negative
                recommendations.append({
                    'rule_id': gate['rule_id'],
                    'gate_name': gate['gate_name'],
                    'recommendation': (
                        f"High false-negative rate ({gate['false_negative_rate']:.1%}). "
                        f"Consider reviewing filter parameters. "
                        f"Estimated alpha recovery: {gate['estimated_alpha_leaked_pct']:.2f}%"
                    ),
                    'potential_alpha_recovery_pct': gate['estimated_alpha_leaked_pct'],
                    'severity': 'high' if gate['false_negative_rate'] > 0.15 else 'medium'
                })

        return sorted(recommendations,
                      key=lambda x: x['potential_alpha_recovery_pct'],
                      reverse=True)
```

```sql
-- ============================================================
-- Migration Script: v0 → v1 (Pick Traceability)
-- Run this after deploying the new tables
-- ============================================================

-- Step 1: Migrate existing active picks
INSERT INTO pick_lifecycle_log (
    pick_id, scan_timestamp, symbol, asset_class, strategy,
    source_system, direction, entry_price, exit_price, pnl_pct,
    confidence, current_stage, stage_timestamp,
    scan_metadata_json, created_at, updated_at
)
SELECT
    CONCAT('legacy_', id) as pick_id,
    COALESCE(created_at, NOW(3)) as scan_timestamp,
    symbol,
    COALESCE(asset_class, 'EQUITY') as asset_class,
    COALESCE(strategy, 'unknown') as strategy,
    COALESCE(source_system, 'legacy') as source_system,
    COALESCE(direction, 'LONG') as direction,
    entry_price,
    exit_price,
    pnl_pct,
    confidence,
    CASE
        WHEN exit_price IS NOT NULL THEN 'closed'
        WHEN is_active = 1 THEN 'active'
        ELSE 'scanned'
    END as current_stage,
    COALESCE(updated_at, NOW(3)) as stage_timestamp,
    NULL as scan_metadata_json,
    COALESCE(created_at, NOW(3)) as created_at,
    COALESCE(updated_at, NOW(3)) as updated_at
FROM picks
WHERE created_at >= DATE_SUB(NOW(), INTERVAL 90 DAY);

-- Step 2: Migrate symbol universe from existing symbol lists
-- (Assumes existing symbols are stored in a symbols table or config)
-- INSERT INTO symbol_universe_registry (...)
-- SELECT ... FROM existing_symbols;

-- Step 3: Create initial history records for migrated symbols
-- INSERT INTO symbol_universe_history (...)
-- SELECT ... FROM symbol_universe_registry;

-- Step 4: Verify migration
SELECT
    current_stage,
    COUNT(*) as count,
    AVG(pnl_pct) as avg_pnl
FROM pick_lifecycle_log
GROUP BY current_stage;

-- Step 5: Create monitoring view for data quality
CREATE OR REPLACE VIEW v_pick_completeness AS
SELECT
    DATE(scan_timestamp) as date,
    asset_class,
    COUNT(*) as total_scanned,
    SUM(CASE WHEN current_stage IN ('active','closed') THEN 1 ELSE 0 END) as passed_through,
    SUM(CASE WHEN current_stage = 'filtered' THEN 1 ELSE 0 END) as filtered_count,
    SUM(CASE WHEN current_stage = 'scanned' THEN 1 ELSE 0 END) as stuck_in_scanned,
    -- Completeness = picks that have either filter event OR reached active
    SUM(CASE WHEN current_stage != 'scanned' THEN 1 ELSE 0 END) / COUNT(*) * 100 as completeness_pct
FROM pick_lifecycle_log
WHERE scan_timestamp >= DATE_SUB(NOW(), INTERVAL 7 DAY)
GROUP BY DATE(scan_timestamp), asset_class
ORDER BY date DESC, asset_class;
```

```python
# File: quality_gates.py (EXISTING — additions only)

# === NEW IMPORTS (Phase 1) ===
from pick_lifecycle_logger import PickLifecycleLogger
from filter_traceback_engine import FilterTracebackEngine

# === NEW: Traceability singletons ===
_pick_logger = None
_filter_tracer = None

def _get_logger():
    global _pick_logger
    if _pick_logger is None:
        _pick_logger = PickLifecycleLogger.get_instance()
    return _pick_logger

def _get_tracer():
    global _filter_tracer
    if _filter_tracer is None:
        _filter_tracer = FilterTracebackEngine.get_instance()
    return _filter_tracer

# === NEW: Decorator ===
def traceable_gate(gate_name: str, rule_id: str):
    """
    Decorator that adds pick traceability to any quality gate.
    Non-breaking: if traceability system is unavailable, falls back
    to original behavior.
    """
    def decorator(func):
        def wrapper(pick: "Pick", *args, **kwargs):
            try:
                result = func(pick, *args, **kwargs)
                if not result:
                    # Pick was filtered — log the event
                    _get_tracer().log_filter(
                        pick_id=getattr(pick, 'pick_id', str(id(pick))),
                        gate_name=gate_name,
                        rule_id=rule_id,
                        reason=f"{gate_name}: {getattr(pick, 'symbol', '?')}/"
                               f"{getattr(pick, 'strategy', '?')} failed {rule_id}",
                        context={
                            "gate_name": gate_name,
                            "rule_id": rule_id,
                            "pick_snapshot": {
                                "symbol": getattr(pick, 'symbol', None),
                                "strategy": getattr(pick, 'strategy', None),
                                "asset_class": getattr(pick, 'asset_class', None),
                                "direction": getattr(pick, 'direction', None),
                                "source_system": getattr(pick, 'source_system', None),
                            }
                        }
                    )
                else:
                    # Pick passed gate — log the pass
                    _get_logger().log_gate_pass(
                        pick_id=getattr(pick, 'pick_id', str(id(pick))),
                        gate_name=gate_name
                    )
                return result
            except Exception as e:
                # CRITICAL: Never let traceability break the gate
                logging.warning(f"Traceability error in {gate_name}: {e}. "
                              f"Falling back to original behavior.")
                return func(pick, *args, **kwargs)
        return wrapper
    return decorator

# === EXISTING FUNCTIONS (unchanged logic, added decorator) ===

@traceable_gate("symbol_blocklist", "RULE-BLOCK-001")
def check_symbol_blocklist(pick) -> bool:
    """Existing function — logic unchanged."""
    return pick.symbol not in BLOCKED_SYMBOLS

@traceable_gate("strategy_blocklist", "RULE-BLOCK-002")
def check_strategy_blocklist(pick) -> bool:
    """Existing function — logic unchanged."""
    return pick.strategy not in BLOCKED_STRATEGIES

@traceable_gate("source_system_blocklist", "RULE-BLOCK-006")
def check_source_systems(pick) -> bool:
    """Existing function — logic unchanged."""
    return pick.source_system not in BLOCKED_SOURCE_SYSTEMS

@traceable_gate("asset_strategy_pairs", "RULE-BLOCK-003")
def check_asset_strategy_pairs(pick) -> bool:
    """Existing function — logic unchanged."""
    return (pick.asset_class, pick.strategy) not in BLOCKED_ASSET_STRATEGY_PAIRS

@traceable_gate("asset_strategy_symbol_triples", "RULE-BLOCK-004")
def check_asset_strategy_symbol_triples(pick) -> bool:
    """Existing function — logic unchanged."""
    return (pick.asset_class, pick.strategy, pick.symbol) \
        not in BLOCKED_ASSET_STRATEGY_SYMBOL_TRIPLES

@traceable_gate("direction_triples", "RULE-BLOCK-005")
def check_direction_triples(pick) -> bool:
    """Existing function — logic unchanged."""
    return (pick.asset_class, pick.strategy, pick.direction) \
        not in BLOCKED_DIRECTION_TRIPLES

# === EXISTING evaluate_quality_gates function (MODIFIED) ===
def evaluate_quality_gates(pick) -> bool:
    """
    MODIFIED: Added scan logging at entry.
    All gate checks remain unchanged.
    """
    # NEW: Log the scan event
    try:
        from pick_lifecycle_logger import PickEvent
        pick.pick_id = pick.pick_id or f"pick_{uuid.uuid4().hex}"
        _get_logger().log_scan(PickEvent(
            pick_id=pick.pick_id,
            scan_timestamp=datetime.utcnow(),
            symbol=pick.symbol,
            asset_class=pick.asset_class,
            strategy=pick.strategy,
            source_system=pick.source_system,
            direction=pick.direction,
            entry_price=pick.entry_price
        ))
    except Exception as e:
        logging.warning(f"Scan logging error (non-critical): {e}")

    # EXISTING: Sequential gate evaluation (now with traceable decorators)
    if not check_symbol_blocklist(pick): return False
    if not check_strategy_blocklist(pick): return False
    if not check_source_systems(pick): return False
    if not check_asset_strategy_pairs(pick): return False
    if not check_asset_strategy_symbol_triples(pick): return False
    if not check_direction_triples(pick): return False

    return True
```

```python
# Test Scenario 1: Complete lifecycle logging
def test_full_lifecycle_logging():
    pick = generate_test_pick(symbol="AAPL", strategy="momentum")
    pick_id = pipeline.process(pick)

    # Verify scan logged
    assert db.query("SELECT * FROM pick_lifecycle_log WHERE pick_id=%s", pick_id).stage == 'scanned'

    passes = db.query("SELECT * FROM gate_pass_log WHERE pick_id=%s", pick_id)

    # Verify activation logged
    pipeline.activate(pick_id)
    assert db.query("SELECT current_stage FROM pick_lifecycle_log WHERE pick_id=%s", pick_id) == 'active'

    # Verify closure logged
    pipeline.close(pick_id, exit_price=200.0, pnl_pct=0.05)
    record = db.query("SELECT * FROM pick_lifecycle_log WHERE pick_id=%s", pick_id)
    assert record.current_stage == 'closed'
    assert record.pnl_pct == 0.05
```

## Appendix A: Glossary

| Term | Definition |
|------|-----------|
| **Pick** | A potential trading signal with symbol, strategy, direction, and metadata |
| **Quality Gate** | A filtering stage (e.g., symbol blocklist check) |
| **Filter Event** | A record that a pick was rejected at a specific gate |
| **Traceback** | Complete reconstruction of a pick's journey through all gates |
| **What-If** | Hypothetical re-evaluation of a filtered pick |
| **False Negative** | A filtered pick that would have been profitable |
| **Alpha Leakage** | Profit opportunity lost due to overly aggressive filtering |
| **Symbol Universe** | Approved set of symbols for trading per asset class |
| **SCD Type 2** | Slowly Changing Dimension — preserves full history |
