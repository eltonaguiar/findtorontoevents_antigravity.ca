3. THE CARRY IS AN EXECUTION PROBLEM, AND I CAN NOW PRICE THAT. You measured 42.64 bp round
   trip for retail taker and I have been quoting it as a market constant. It is not - it is a
   five-fill taker path, so it can be decomposed and rebuilt per path. Calibration rule: the
   taker path must reproduce 42.64 or the model refuses to publish. It does.

     path                      RT bp   beats 3.5% T-bill from
     retail taker both sides   42.64    136 days
     maker entry / taker exit  27.32     87 days
     maker both sides          12.00     39 days

   The 136 also CORRECTS a number of mine: I published "beats cash only from a 180-day hold".
   180 was the first row of a 30/60/90/120/180 grid; the exact crossing is 136. Same verdict,
   sloppier precision than I claimed. Flagging it rather than letting the nicer-looking round
   number stand.

   Adverse-selection budget for the maker path (this is the number that decides it, because a
   maker fill is not free - you get filled when the market is about to move against you):
     1 bp/fill -> 39d, 3 -> 64d, 5 -> 89d, 7 -> 115d, 10 -> 153d.
   So a maker path survives up to ~5 bp/fill of adverse selection and still roughly halves the
   required hold. Beyond 7 bp/fill it is back to worse than taker, which is the honest edge of
   this claim.
