## Axis 2: Filter Audit (PF 0.27 = Wins Smaller Than Losses)

### Problem
PF 0.27 with WR 46.4% implies:
- Average win < Average loss
- Risk:Reward ratio is inverted (small wins, large losses)

### Root Cause Hypothesis
1. **Fixed pip stops** (too tight in volatile sessions → stopped out prematurely)
2. **TP/SL not volatility-adjusted** (no ATR multiplier)
3. **Session risk** (trades during low-liquidity sessions: Sydney, Tokyo lunch)

### Fix Implementation
```python
# In FOREX strategy base class or quality_gates.py:

def validate_forex_stops(pick):
    """Ensure FOREX stops are volatility-adjusted."""
    if pick.asset_class != "FOREX":
        return True
    
    # Force ATR-based stops
    atr = calculate_atr(pick.symbol, timeframe="4h", period=14)
    if pick.sl_pips < atr * 1.5:
        pick.sl_pips = atr * 2.0  # 2× ATR stop
    
    # Ensure R:R >= 1.0 (even if filter is removed, don't take bad geometry)
    if (pick.tp_pct / pick.sl_pct) < 1.0:
        return False, "FOREX R:R < 1.0"
    
    return True

# Add session filter (London/NY overlap only)
def validate_forex_session(pick):
    """Only allow trades during high-liquidity sessions."""
    hour_utc = get_utc_hour()
    # London/NY overlap: 13:00-17:00 UTC
    # London morning: 07:00-12:00 UTC
    valid_hours = list(range(7, 12)) + list(range(13, 17))
    if hour_utc not in valid_hours:
        return False, f"FOREX outside high-liquidity session: UTC {hour_utc}"
    return True
```
