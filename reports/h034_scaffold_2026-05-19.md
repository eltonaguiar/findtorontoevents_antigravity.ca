### The signal

Gorton-Rouwenhorst (2006, *Facts and Fantasies about Commodity Futures*)
documented that the cross-section of commodity-futures' basis (front-vs-second-
month roll yield) carries a stable risk-premium. The canonical sort:

- **LONG** the top quintile of liquid commodity futures ranked by basis /
  roll-yield (most-backwardated = positive expected roll yield).
- **SHORT** the bottom quintile (most-contangoed = negative expected roll).
- Weekly (or monthly) rebalance; market-neutral long-short basket.

Construction in this scaffold:

- `basis_proxy(i, D) = ln(close(i, D) / close(i, D-21))` — a **trailing-return
  basis proxy** (honest stand-in; yfinance does not expose a free true
  second-month series).
- `signal_z(i, D)` = rolling 60-observation strictly-past z-score of
  `basis_proxy(i, *)`.
- Cross-sectional rank across the universe at D: top 20% → LONG (+1),
  bottom 20% → SHORT (-1), middle quintiles skipped.
- Harness score field = `|signal_z|` (conviction magnitude).
- Rebalance every 5 trading days; hold 5 days.

**Causal mechanism:** the long-short quintile basket survives in the canonical
Gorton-Rouwenhorst paper across decades — backwardated curves embed positive
expected roll returns, contangoed curves vice-versa. This is **structurally
different** from the killed H-007 (`front_second_roll_yield_zscore`, single-
asset directional z-score on an ETF proxy that failed sign-stability): H-034 is
**cross-sectional and rank-based**, not per-asset directional.

### Construction caveat — yfinance stitched continuous vs true CME spread

yfinance =F tickers are STITCHED front-month continuous series — the roll bumps
inject some noise vs a true CME front-vs-second-month calendar-spread feed
(Quandl CME WIKI). The cross-sectional **rank** across commodities is the part
the Gorton-Rouwenhorst sort cares about (not the absolute basis level), so the
proxy is honest *for the sort*. A true Quandl CME WIKI front/second feed would
be a sharper test and is the documented data-upgrade path before any wire-up
consideration. `basis_proxy_mode = "front_return_zscore"` is stamped in the
registry, the cache file, and every report header for traceability.

futures universe — different construction, different harness record stream,
different signal family entirely. The M-107 banned-family check explicitly

```bash
python tools/h034_commodity_term_structure_research.py

python tools/h034_commodity_term_structure_research.py --refresh-cache
```

Output report: `reports/h034_commodity_term_structure_research_2026-05-19.md`.
Data cache: `tools/cache/h034_commodity_term_structure_cache.json`.

The verdict is one of `ADMISSIBLE`, `REJECTED`, or `UNTESTED-data-gap`. A gaudy
in-sample WR is NOT a pass — only the harness + post-cost verdict counts.

**Known data caveats:**
- yfinance =F continuous is a STITCHED series; the basis proxy is a trailing-
  return stand-in. A true CME front/second calendar-spread feed is the natural
  next-step data upgrade.
- If yfinance is unreachable the run falls back to a labelled synthetic series
  per ticker and forces `UNTESTED-data-gap`.
- CT=F is in the harness universe by design but on the production
  `COMMODITY_BLACKLIST`; this sidecar emits no picks.

## Wiring Plan

H-034 is an **opt-in sidecar today** and stays that way until it clears the
harness gate. Per the CLAUDE.md Wire-Up Rule, here is the explicit wire-up path:

- **Target caller file:** `audit_trail/quality_gates.py`
- **Target function:** `passes_active_gate(...)` — the production pick gate.
  H-034 would contribute a `commodity_basis_quintile_z` feature read by the
  gate for `asset_class == "COMMODITY"` picks (and surface in
  `audit_trail/dashboard_generator.py::calculate_smart_score` as a scoring
  input).
- **Pre-wire-up harness-gate condition (HARD GATE — all must hold):**
  1. `tools/h034_commodity_term_structure_research.py` must report
     `VERDICT: ADMISSIBLE` — `tools/edge_stability_harness.is_admissible()`
     returns `True`: `|eff| >= 0.30`, **same sign**, in `>= 3 of 5` walk-
     forward 14-day windows, each window `>= 80` records.
  2. The post-cost gate must PASS — net edge retains `>= 60%` of gross after a
     15bps commodity-futures round-trip (includes futures roll cost both legs).
  3. The run must NOT be on a synthetic/offline fallback series — it must use
     a live yfinance =F tape OR a true CME front/second calendar-spread feed.
  4. The basis proxy must be re-tested against a **true CME front/second
     calendar-spread feed** (Quandl CME WIKI continuous chains) — the
     trailing-return proxy only pre-screens; a real calendar-spread run is the
     genuine test.
  5. A fresh **out-of-sample** re-test on data collected after the
     `data_sample_lock` must also clear (1)+(2).
  6. A deflated-Sharpe / SPA multiple-testing correction and operator sign-off.
  7. CT=F is excluded from any production emission regardless of harness
     verdict (it remains in the harness universe for cross-sectional ranking
     only).
- **If any condition fails:** archive the H-034 config, mark the registry row
  `REJECTED`, record the `next_step`, and **do NOT re-test the same
  construction on the same sample** (M-107). A real calendar-spread run is a
  distinct test and is permitted; a re-run of the trailing-return proxy on
  this sample is not. No wiring.

Until (1)-(7) all hold, H-034 has **zero production callers** and changes
**zero production behaviour**.
