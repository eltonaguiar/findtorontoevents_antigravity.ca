## The actual edge map

### Clear edge

1. **ETF rotation + event regimes**
   - `etf_sector_leader_rotation`: 33.33% WR, PF 1.24, walk-forward pass
   - `etf_commodity_divergence_breakout`: 39.44% WR, PF 1.31, walk-forward pass
   - `etf_volatility_crush_reentry`: 66.67% WR, PF 4.08, small sample but very strong
2. **Forex short-horizon mean reversion**
   - `forex_rsi2_snapback`: 60.42% WR, PF 1.90, walk-forward pass, Monte Carlo profit probability 99.8%
   - `forex_dollar_exhaustion_fade`: 47.37% WR, PF 1.39, walk-forward pass
3. **Futures compression / pullback**
   - `futures_momentum_compression_breakout`: 43.66% WR, PF 1.65, walk-forward pass
   - `futures_index_trend_pullback`: 41.42% WR, PF 1.18, walk-forward pass
4. **Commodity rebound / structural rotation**
   - `commodity_crude_crash_rebound`: 46.67% WR, PF 1.25
   - `commodity_copper_growth_reversal`: 35.51% WR, PF 1.05, walk-forward pass

### Weak / not yet portable edge

1. **Crypto daily setups are not where this repo’s strongest edge lives.**
   - None of the 5 new daily crypto strategies beat the 42.8% class WR baseline.
   - Best result was still `crypto_relative_strength_rotation`, but only 31.18% WR / PF 1.05 after retuning.
   - This lines up with existing repo evidence that stronger crypto edge is in **specific 4h/intraday continuation and symbol-specific variants**, not broad daily cross-sectional rules.
2. **Equities improved PF but not enough WR.**
   - `equity_quality_trend_pullback`: PF 1.57, WR 42.37%
   - `equity_pead_gap_followthrough`: WR 46.51%, PF 0.85
   - Translation: the equity book likely has a split edge between **trend pullbacks** and **event gaps**, but not a single daily template that dominates both.

## Bottom line

This wave **did** find fresh edge in ETFs, futures, parts of forex, and parts of commodities. It **did not** validate a broad daily crypto or equity edge, which is useful because it narrows the next move:

1. keep the ETF / futures / forex winners,
2. treat commodity winners as greenfield adds,
3. stop pretending daily crypto/equity templates are the main edge,
4. push the next crypto/equity round toward intraday continuation, event inputs, and symbol-specific rehab instead of more generic daily indicator blends.
